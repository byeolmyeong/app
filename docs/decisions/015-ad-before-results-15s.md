# 015. 1.1.0 부터 결과를 보기 전에 15초 광고를 보여 주고, 같은 결과를 다시 열 때는 보여 주지 않는다

> 상태: 활성 · 결정일 2026-11-11 · 출처: docs/raw/2026-11-11-session-planning-1.0.0.md · docs/decisions/008-ads-and-ad-removal.md 의 "1.1.0 부터 결과를 보기 전에 광고"에 길이·대상·반복 규칙을 더한다(008 의 나머지는 그대로)

## 맥락
결정 011·014 로 1.0.0 의 리포트·궁합은 횟수 제한 없이 무료가 되었고, 심층·궁합 리포트는 앞으로도 무료다. 유료로 바꾸는 것은 방향성 제시뿐이라 무료 사용자의 AI 비용을 메울 수익원은 광고가 맡는다. 결정 008 은 광고 시점(1.1.0, 결과 전)만 정하고 길이·대상·반복 규칙은 정하지 않았다. 소유자는 광고를 1.0.0 으로 당기는 것을 검토했다가 1.1.0 그대로 두기로 했다.

## 결정
- 광고는 결정 008 그대로 1.1.0 부터 넣는다. 1.0.0 에는 광고가 없다.
- 결과를 보기 전에 15초 광고를 보여 준다. 광고를 끝까지 보면 결과가 열린다.
- 대상 결과: 요약 해석, 심층 리포트, 궁합 결과, 궁합 리포트, 방향성 제시.
- 같은 결과를 다시 열 때는 광고를 다시 보여 주지 않는다. 광고는 결과마다 처음 한 번만 나온다.
- 990원 광고 제거 상품도 1.1.0 부터 판다(결정 008).

## 근거
- 무료로 주는 기능이 늘어난 만큼 광고가 AI 비용을 메운다.
- 15초는 결과를 기다리는 시간(리포트 생성 중)과 겹쳐 체감이 덜하다.
- 이미 본 결과에 광고를 다시 붙이면 랭킹·리포트를 다시 보러 오는 재방문을 깎는다.
- 1.0.0 에 광고 SDK 를 넣지 않으면 개인정보 처리방침·스토어 데이터 수집 신고·추적 허용 요청을 1.0.0 범위에서 뺄 수 있다.

## 대안
- 1.0.0 부터 광고 — 비용은 일찍 메우지만 출시 준비 범위가 늘어난다. 사용자가 1.1.0 으로 미뤘다.
- 첫 요약 해석만 광고 없이 — 첫인상 이탈을 줄인다. 1.1.0 계획에서 다시 본다.

## 결과·재검토 조건
- 1.1.0 에 광고 SDK 가 들어간다. 개인정보 처리방침과 스토어 데이터 수집 신고를 고치고, iOS 는 추적 허용 요청(ATT)이 필요할 수 있다.
- 확산 타깃에 만 14~18세가 있다. 미성년자에게는 맞춤형 광고를 끈다. [확인 필요] 광고 SDK 의 연령 설정.
- 광고 시청 여부는 서버가 판정한다(앱의 값으로 결과를 열지 않는다, docs/golden-rules.md 프로젝트 규칙). [확인 필요] 광고 SDK 의 서버 검증 방식.
- [확인 필요] 첫 요약 해석 앞에도 광고를 둘지, 웹에서도 광고를 보여 줄지, 광고를 불러오지 못하면 결과를 그냥 열지.
- 1.0.0 은 광고 없이 무료로 운영하므로 출시 후 AI 비용을 본다.
