# 094. 하위 화면 · 가입 단계는 밀려 들어오지 않고 바로 바뀌고, 앱 뒤 바탕은 어둡다. 시트 · 펼침은 조금 느리게, 홈 슬라이드는 왼쪽에서 자른다

> 상태: 활성 · 결정일 2026-11-26(소유자, 테스트앱 빌드 15) · 화면 쌓기의 "탭 안에서 들어가는 화면은 기본(오른쪽에서) 그대로"(#89 의 주석)를 대체한다 · 결정 068 의 7 중 "다음 단계는 오른쪽에서 밀려 들어오고 뒤로는 오른쪽으로 나간다"를 대체한다(빈 화면 없음 · 화면 조각을 나누지 않음은 그대로) · 결정 092 의 4(이번 달 눈여겨볼 날 가로 슬라이드)에 자르는 자리를 더한다 · 1.0.0(빌드 16)

## 맥락
- 2026-11-21 소유자: "뎁스가 있는 화면으로 넘어갈 때도 오른쪽에서 왼쪽으로 오는 애니메이션이 있는 것 같은데 이것도 좀 수정해 봐." 그때는 밀기를 매끄럽게만 했다(#104).
- 빌드 15 소유자: "아직도 오른쪽에서 왼쪽으로 페이드되면서 화면 바뀌는데 이거 안 되게 하라니까. 모서리 쪽에 흰색 배경이 계속 보여, 살짝 넘어가면서."
  - 앱 설정에 앱 뒤 바탕(`expo.backgroundColor`, root view)이 없어 흰색이었다. 화면이 밀리는 동안 기기 모서리로 비쳤다.
- 빌드 15 소유자: "이렇게 풀이한 이유 지금 펼쳐질 때 너무 빠른데 조금만 느리게", "내 하늘 지도 바텀시트도 올라올 때 속도가 좀 너무 빨라." 둘 다 `Motion`(열기 300 · 닫기 220)을 쓴다.
- 빌드 15 소유자(하위 화면 결정 뒤): "가입 단계도 그냥 바로 넘어가게 해 줘."
- 빌드 15 소유자: 이번 달 눈여겨볼 날 "슬라이드는 잘 되는데 왼쪽에 넘치게 하는데?? … 안 넘치게 막아 줘."

## 결정
1. **화면 쌓기 기본은 `animation: 'none'`**: 탭 안에서 들어가는 화면(내 별명 · 내 하늘 지도 · 시기 자세히 · 그날의 하늘 · 오늘의 하늘 · 마이의 하위 화면 · 알림함 등)과 가입 단계(약관 → 닉네임 → 출생 정보)도 탭 첫 화면처럼 바로 바뀐다.
   - 약관 글 네 화면만 아래에서 올라온다(결정 067 의 1).
   - 웹 가입 단계가 스스로 오른쪽에서 밀려 들어오던 것(앞 화면을 남기는 transparentModal + `useSlideUp('right')`)도 뺀다. 가입 단계는 다른 화면처럼 보통 화면으로 쌓인다.
2. **앱 뒤 바탕은 화면 바탕과 같은 `#0D0E12`**(app.json `expo.backgroundColor`). 새 앱 빌드부터 적용된다.
3. **`Motion` 은 열기 420 · 닫기 280**(곡선은 그대로 bezier(0.32, 0.72, 0, 1)). 아래 시트 · 아래에서 올라오는 창 · 이유 펼침 · 자주 묻는 질문 펼침이 같이 느려진다. 한 값을 같이 쓰는 규칙은 그대로다.
4. **이번 달 눈여겨볼 날 슬라이드는 왼쪽을 홈 여백(20)에서 자르고 오른쪽만 화면 끝까지** 간다. 다음 칸이 오른쪽에 걸쳐 보여 밀 수 있다는 걸 알린다.

## 대안
- 하위 화면을 흐려지며 바뀌게(`fade`) — 소유자가 말한 "페이드되면서"와 겹치고, "안 되게"에 맞지 않는다.
- 이유 펼침만 따로 느리게 — 시트도 같은 지적이 와서 한 값을 같이 늘렸다.
- 슬라이드 양쪽 다 홈 여백에서 자르기 — 다음 칸이 덜 보여 밀 수 있다는 신호가 약해진다. 소유자는 왼쪽만 말했다.

## 결과
- 하위 화면에서 뒤로 갈 때도 움직임 없이 바로 돌아간다. iOS 의 왼쪽 끝에서 끌어 뒤로 가기가 그대로 되는지는 빌드 16 에서 확인한다.
- 가입 단계의 진행 막대 움직임은 그대로다(화면 넘김과 별개).
