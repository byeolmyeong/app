# 005. 로그인은 구글·애플만, 해석을 받을 때 요구한다

> 상태: 대체됨 → docs/decisions/009-signup-first-kakao-age14.md · 결정일 2026-11-10

## 맥락
1.0.0 은 웹과 스토어 앱에 동시에 낸다. 해석은 서버에 저장하므로 누구의 것인지 알아야 한다. 처음 설계는 로그인 없는 기기별 익명 계정이었고, 사용자가 구글·애플 로그인만 구현하기로 정했다.

## 결정
로그인 수단은 구글과 애플 두 가지만 둔다. 익명 계정은 만들지 않는다. 출생 정보 입력과 차트는 로그인 없이 쓰고, 서버가 필요한 기능(요약 해석, 궁합)을 처음 쓸 때 로그인을 요구한다.

## 근거
- 차트는 기기 안에서 계산되므로 로그인 없이 보여 줄 수 있다. 첫 화면의 가입 장벽이 없다.
- 익명 계정이 없으면 익명 → 로그인 계정 병합을 만들 필요가 없다.
- AI 해석을 로그인한 사용자에게만 생성해 비용 남용을 막는다.
- Apple 은 외부 로그인을 넣은 앱에 애플 로그인도 요구한다. 구글·애플 조합은 이 요건을 채운다.

## 대안
- 익명 계정만 — 구현이 가장 작지만 기기를 바꾸면 기록이 사라진다. 사용자가 택하지 않았다.
- 카카오 로그인 — 한국 사용자에게 익숙하지만 사용자가 구글·애플만으로 정했다.
- 로그인 필수(첫 화면) — 차트를 보기도 전에 이탈한다.

## 결과·재검토 조건
- 계정 삭제 기능이 필수가 된다(Apple 심사 요건).
- 웹과 Android 에서의 애플 로그인은 웹 방식 인증을 거친다. 구현 전에 Expo 공식 문서로 방법을 확인한다.
- 로그인 전환율이 낮으면(차트를 본 사용자 중 해석까지 가는 비율) 카카오 로그인 추가나 로그인 없는 미리보기를 다시 본다.
