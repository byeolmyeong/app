# MVP: 출생 차트 + AI 해석 + 궁합 + 건당 결제

> 상태: 중단 → docs/plans/2026-11-10-app-1.0.0.md 로 대체 · 기준 2026-11-10 · 태스크 1 만 완료됐고, 범위가 1.0.0 기능 명세(docs/release-1.0.0.md)로 바뀌어 나머지는 새 계획에서 다시 잡았다.

## 목표
- 무엇을: 출생 정보로 차트를 계산하고, 용어 없는 AI 해석과 궁합을 보여 주고, 심층 리포트를 앱에서 건당 판매한다.
- 누구를 위해: 자기 이해 콘텐츠를 즐기는 한국어 사용자.
- 끝나면: 웹에서 차트·요약 해석·공유가 되고, iOS·Android 앱에서 심층 리포트와 궁합을 살 수 있다.

## 범위 조정 (2026-11-10, 사용자 결정)
- 결제와 그에 딸린 것은 빼고 핵심 기능부터 만든다. 태스크 9(인앱결제)·11(스토어 제출 준비)은 보류한다.
- 태스크 6 의 `purchases` 테이블과 태스크 7 의 구매 확인·차감은 결제를 붙일 때 넣는다. 그때까지 심층 리포트·궁합 리포트는 구매 확인 없이 열린다.
- 실행 순서: 1 → 2 → 3 → 4 → 5 → 8(계산·무료 화면) → 6 → 7 → 10. 6·7·10 은 서버 저장소의 선행 태스크가 끝나야 시작한다.
- 결제 방식 결정(docs/decisions/002-iap-only-per-report.md)은 그대로 유효하다. 시점만 뒤로 미룬다.
- 앱과 서버는 저장소를 따로 둔다(docs/decisions/004-spring-backend.md). 서버 부분은 서버 저장소의 계획(`../byeolmyeong-api/docs/plans/2026-11-10-api-mvp.md`)으로 옮겼다. 이 파일의 태스크 6·7·10 은 앱 쪽만 다루고 서버 태스크를 선행으로 가리킨다.

## 내 결정 (묻지 않고 고른 기본값)
- 앱 명령은 Node 22 로 돌린다(`.nvmrc`).
- 해석 생성은 OpenAI API 를 쓴다(사용자 결정). 서버 쪽 결정은 서버 저장소에 있다.
- 로그인 없이 기기별 익명 계정(서버가 발급한 토큰)으로 시작한다. 소셜 로그인 연결은 범위 밖(나중).
- 하우스는 플라시더스, 고위도는 홀 사인으로 대체.
- 출생지는 국내 시·군·구 목록을 앱에 내장한다(검색 API 없음).
- 해석은 차트당 한 번 생성해 저장한다.
- 테스트 러너는 Jest(jest-expo).

## 범위 밖
- 오늘의 운세·트랜싯·푸시, 사주·타로, 해외 출생지·다국어, 구독, 상담 연결, 소셜 로그인 연결.
- 스토어 제출 자체(심사 요청). 제출 준비물까지만 한다.

## 전역 제약
- 패키지 설치는 `npx expo install <패키지>` 만 쓴다(SDK 호환 버전).
- Expo·EAS·React Native API 를 쓰는 코드는 쓰기 전에 `package.json` 의 expo 버전에 맞는 공식 문서를 확인한다(AGENTS.md).
- `src/features/chart/` 는 화면·네트워크·저장소를 import 하지 않는다.
- API 키는 서버 환경 변수에만 둔다. 이름은 `.env.example`, 값은 커밋하지 않는다.
- 해석·문구에 건강·투자·미래 사건의 단정 표현을 쓰지 않는다.
- 출생 정보를 로그에 남기지 않는다.

## 검증

## 리뷰 초점
1. 시각 "모름" + 궁합: 한쪽만 시각을 모를 때 하우스 기반 문장이 해석에 섞이지 않는가 (태스크 7·8).
2. 자정 직전 출생 + UTC+8:30 시기: 날짜가 넘어가며 달 별자리가 바뀌는 경우 (태스크 4).
3. 별자리 경계 29.99도: 반올림으로 다음 별자리로 표시되지 않는가 (태스크 2).
4. 해석 생성이 오래 걸릴 때: 화면이 멈춘 것처럼 보이지 않고 다시 시도가 중복 요청을 만들지 않는가 (태스크 7).
5. 익명 토큰 분실: 앱 데이터를 지우면 이전 해석을 다시 볼 수 없다. 안내 문구가 있는가 (태스크 6).

## 위험 · 되돌리기
- 직접 구현한 하우스 계산이 기준값과 안 맞을 수 있다. 3회 미달이면 홀 사인만으로 출시하고 ADR 003 을 고친다.
- 스토어 심사에서 점술 콘텐츠·AI 생성 콘텐츠로 반려될 수 있다. 면책 문구와 처리방침으로 대비하고, 반려 사유는 `docs/raw/` 에 남긴다.
- AI 해석 비용이 건당 가격보다 커질 수 있다. 태스크 7 에서 리포트 1건의 실제 비용을 재서 실행 기록에 적고 가격 결정의 입력으로 쓴다.
- 작업은 태스크별 브랜치에서 한다. 태스크 하나 = 커밋 하나라 되돌릴 때는 그 커밋만 revert 한다.
