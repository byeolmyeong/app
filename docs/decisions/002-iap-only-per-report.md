# 002. 결제는 스토어 인앱결제만, 리포트 건당으로 판다

> 상태: 활성 · 결정일 2026-11-10 · 보완: docs/decisions/008-ads-and-ad-removal.md (광고, 990원 광고 제거 상품, 방향성 제시 VIP 추가)

## 맥락
수익원은 심층 리포트와 궁합 리포트다. 결제 수단은 인앱결제만 쓰기로 사용자가 정했다. MVP 에는 매일 새로 볼 콘텐츠(오늘의 운세)가 없다.

## 결정
결제는 App Store·Google Play 인앱결제만 쓰고, 상품은 리포트 건당 구매(소모성)로 한다. 구매 처리와 확인은 RevenueCat 을 쓴다. 웹에서는 결제하지 않고 앱으로 유도한다.

## 근거
- 건당 구매는 한국 운세 앱 사용자에게 익숙하고, 구독보다 상품 구조와 심사가 단순하다.
- 구독은 매달 볼 새 콘텐츠가 있어야 유지되는데 MVP 범위에 없다.
- RevenueCat 은 두 스토어의 구매·영수증 확인을 한 API 로 묶는다.

## 대안
- 월 구독 — 오늘의 운세가 들어온 뒤에 다시 본다.
- 재화 충전 — 잔액 관리와 환불 처리가 복잡하다.
- 웹 결제(PG) — 수수료는 낮지만 사용자가 인앱결제만 쓰기로 했다.

## 결과·재검토 조건
- 스토어 수수료 15%(소규모 사업자 프로그램)~30%를 낸다.
- 웹 사용자는 결제하려면 앱을 설치해야 한다. 웹 → 앱 전환율이 낮으면 웹 결제를 다시 본다.
- 가격은 미정이다. [확인 필요] docs/product.md
