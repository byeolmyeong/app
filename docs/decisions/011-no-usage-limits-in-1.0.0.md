# 011. 1.0.0 은 리포트와 궁합에 횟수 제한을 두지 않는다

> 상태: 활성 · 결정일 2026-11-11 · 출처: docs/raw/2026-11-11-session-planning-1.0.0.md · docs/release-1.0.0.md 의 "무료지만 횟수를 제한한다"(리포트 계정당 1편, 궁합 하루 5번)를 바꾼다

## 맥락
1.0.0 명세는 결제 없이 심층 리포트·궁합 리포트를 계정당 1편, 궁합 결과를 하루 5번으로 제한했다. 궁합 랭킹(docs/decisions/010-synastry-score-ranking-share-cards.md)과 조각(F11)은 궁합을 여러 번 봐야 쌓인다.

## 결정
- 1.0.0 은 심층 리포트, 궁합 리포트, 궁합 결과를 횟수 제한 없이 무료로 준다.
- 같은 차트(같은 두 사람)의 글은 한 번만 만들고 다시 열면 같은 글을 준다(기존 규칙 그대로).
- 자동화·남용 같은 비정상 반복 요청은 서버 보호용 요청 속도 제한으로 막는다. 기능의 횟수 제한과는 별개다.

## 근거
- 랭킹과 조각이 쌓이려면 궁합을 많이 봐야 한다. 하루 5번은 친구들을 넣어 보는 흐름을 끊는다.
- 같은 글을 다시 생성하지 않으므로 AI 비용은 새 차트·새 상대 수만큼만 든다.

## 대안
- 리포트 1편 유지, 궁합 횟수만 늘리기 — 비용은 묶지만 사용자가 제한 없이 쓰기를 택했다.
- 기존 제한 유지 — 랭킹이 쌓이지 않는다.

## 결과·재검토 조건
- docs/product.md 의 "유료 리포트를 1.0.0 에서 무료로 풀지 않는 이유"를 뒤집는다. 1.1.0 에서 무엇을 유료로 할지(추가 리포트, 방향성 제시 VIP, 광고 제거)는 이 결정에 맞춰 다시 정한다. 결정 002·008 과 함께 본다.
- 출시 기준의 "리포트 무료 1편, 궁합 하루 5번이 서버에서 지켜진다"를 지운다.
- 출시 후 하루 생성 건수와 AI 비용을 본다. 비용이 감당하기 어려우면 1.0.x 에서 제한을 다시 둔다.
