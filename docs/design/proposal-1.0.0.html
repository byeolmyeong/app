02

기능 아홉 가지

기능로그인무엇을 하는가지키는 규칙
F1출생 정보 입력불필요생년월일, 출생 시각(분 단위 또는 "모름"), 국내 시·군·구를 받는다. 기기에 저장해 다시 열면 복원한다.1900년 이전과 미래 날짜는 받지 않는다. 한국 표준시 변경과 서머타임 이력을 반영한다.
F2출생 차트불필요서버가 계산한다. 차트 휠, 태양·달·상승궁, 그리고 전체 수치 표(행성·교점·릴리스·행운점, 하우스 12개, 각도와 오차).시각이 "모름"이면 하우스와 상승궁을 보여 주지 않는다. 키론은 정확도를 검증한 뒤 넣을지 정한다.
F3내 별명
요약 해석		필요한 줄 총평 → 중심 → 마음 → 첫인상과 지향 → 힘이 몰린 곳 → 과제 → 강점·보완점. 횟수 제한 없음.본문에 점성술 용어를 쓰지 않고 문단 머리에 근거를 표시한다. 건강·투자·미래를 단정하지 않는다. 같은 차트는 항상 같은 글.
F4심층 리포트필요성격·관계·일·감정·시기 다섯 영역의 긴 글. "시기"는 인생의 변곡점이 오는 해를 계산해 보여 준다.계정당 1편 무료. 시기는 "이 시기의 주제"만 쓰고 무슨 일이 일어난다고 쓰지 않는다.
F5궁합필요상대 정보를 직접 넣거나 초대 링크를 보낸다. 키워드 3개와 한 줄 요약, 겹친 차트. 궁합 리포트(끌림·대화·갈등·오래가기).점수를 보여 주지 않는다. 키워드는 하루 5번, 리포트는 계정당 1편. 직접 넣은 상대 정보는 저장하지 않고, 초대한 상대의 생년월일은 서로 보이지 않는다.
F6공유불필요
(열람)		내 별명과 궁합 결과를 링크로 공유한다. 링크는 로그인 없이 열리고 "내 별명 보러 가기"로 이어진다.공유 페이지에 생년월일·시각·출생지를 노출하지 않는다. 리포트는 공유하지 않는다.
F7로그인 · 계정—구글·애플 로그인. 내 출생 정보·해석·리포트·연결된 궁합이 계정에 저장되어 다른 기기에서도 보인다.F3·F4·F5 를 처음 쓸 때만 요구한다. 앱 안에서 계정을 삭제할 수 있다.
F8푸시 알림필요궁합 초대가 수락됐을 때, 리포트가 완성됐을 때 알린다. 앱에서만 보낸다.허용은 첫 실행 때가 아니라 필요한 순간에 묻는다. 광고 알림은 보내지 않는다.
F9설정 · 안내불필요알림, 처리방침, 약관, 문의, 버전, 로그아웃, 계정 삭제.해석 화면마다 "오락과 자기 성찰을 위한 내용" 문구를 둔다.

03

차트까지는 로그인 없이, 글을 받을 때 로그인

첫 화면에서 막지 않는다. 차트는 로그인 없이 보여 주고, 글을 받는 순간에만 로그인을 요구한다.

1

출생 정보 입력

날짜 · 시각 · 출생지. 시각을 모르면 "모름".

2

차트 보기

차트 휠과 전체 수치. 여기까지 로그인 없이.

여기서 로그인
3

내 별명 읽기

요약 해석. 문단마다 근거 표시.

4

더 깊이 읽기

심층 리포트 다섯 영역과 인생의 변곡점. 완성되면 알림.

5

공유

받은 사람은 로그인 없이 읽고 자기 차트를 만들러 온다.

궁합 1

상대 정하기

초대 링크를 보내거나 상대 정보를 직접 넣는다.

궁합 2

초대 수락

상대가 로그인하고 자기 정보를 넣는다. 서로의 생년월일은 보이지 않는다.

궁합 3

관계 키워드

낱말 세 개와 한 줄 요약, 겹친 차트. 수락되면 알림.

궁합 4

궁합 리포트 · 공유

네 영역의 긴 글. 키워드 결과는 링크로 공유한다.

화면 열두 개

입력(홈) · 차트 · 차트 자세히 · 내 별명 · 심층 리포트 · 궁합 시작 · 궁합 결과 · 궁합 리포트 · 초대 수락 · 공유 페이지 · 로그인 · 설정

들어오는 길 두 가지

공유 링크를 읽고 "내 별명 보러 가기"로 들어온다.
궁합 초대 링크를 받아 수락하며 들어온다.

05

디자인은 "도장과 책력"

화면 시안은 따로 둔 HTML 파일(screens-1.0.0.html)에 있다. 여기에는 기준만 적는다.

방향

흰 종이에 검은 글씨. 색은 인주 빨강 하나.
"별명"을 이름 도장으로 쓴다. 글이 완성된 자리에 찍힌다.
차트 수치는 옛 달력(책력)의 표처럼 가는 선으로 보여 준다.
상자와 그림자 대신 선과 여백으로 나눈다. 모서리는 거의 둥글리지 않는다.
빨강은 한 화면에 한 곳. 주 버튼도 한 화면에 하나.
그라데이션, 빛 번짐, 이모지, 캐릭터, 점수를 쓰지 않는다.

확인이 필요한 것

1키론 — 별도 궤도 데이터가 필요하다. 정확도를 검증한 뒤 차트 표와 "시기"(만 50세 무렵의 키론 귀환)에 넣을지 정한다
2무료 횟수 — 심층 리포트 1편, 궁합 리포트 1편, 궁합 키워드 하루 5번으로 잡았다
3초대 링크 — 7일 동안 한 사람만 쓸 수 있게 잡았다
4궁합 공유 — 초대로 연결된 궁합은 두 사람 누구나, 직접 입력한 궁합은 입력한 사람만 공유할 수 있게 잡았다
5이름 — "별명" 상표와 스토어 동명 앱을 아직 확인하지 않았다
