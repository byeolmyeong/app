# 1.0.0 기획안

> 기준 2026-11-11 · 디자이너 공유용 최종 정리본. 이후 바뀐 것: 앱 이름은 "별명" 그대로(결정 032), 디자인은 어두운 브랜딩(결정 033 · 035), 설정 화면은 마이에 합쳤다(결정 038), 로그인은 소셜 로그인(결정 034) — 이 문서의 해당 줄보다 결정이 먼저다. 피그마 "기획" 프레임(1632×980)용 보드: docs/design/product-brief-1.0.0.png (원본 product-brief-1.0.0.svg). 결정 근거는 docs/decisions/009~015, 명세는 docs/release-1.0.0.md

## 한 문장

**점성술 몰라도 읽히는 나, 나의 사람들, 나의 타이밍**

가입하고 출생 정보를 넣으면 버튼 하나로 "나를 설명해 주는 글"을 받고, 사람마다 다른 인생의 변곡점을 읽고, 나 기준으로 여러 사람과 궁합 점수를 보고 랭킹을 만들고, 결과를 스토리 카드로 공유한다.

- 앱 이름은 바꾼다. 새 이름은 브랜딩에서 정한다
- 1.0.0 대표 문구는 새로 정한다

## 타깃

| | 누구 | 궁금한 것 |
|---|---|---|
| **핵심** | 20대 초반~30대 초반 (여성 중심) | 연애 · 궁합, 전환기에 "나 지금 어떤 시기야?" · 오래 쓰고 깊게 본다 |
| **확산** | 10대 후반 (만 14세 이상) | 친구 궁합, 진로와 미래, 내 변곡점 · 예쁜 결과를 스토리에 올린다 |
| **공통** | 점성술은 잘 모른다 | "왜 그런지" 납득하고 싶다 · 결과를 스토리로 공유한다 |

- 기능은 타깃별로 나누지 않는다. 말투가 부딪히면 핵심 타깃을 따른다
- 가입은 만 14세 이상만 받는다

## 차별점 — 점성술 몰라도 읽힌다

- 해석 본문에 점성술 용어를 쓰지 않는다
- 문단마다 "왜 그런지" 근거(차트 요소)를 표시한다
- 단정하지 않고 "이 시기의 주제"로 말한다
- 고정 문구 조합이 아니라 차트 전체를 엮은 개인화 해석이다

## 1.0.0 원칙

- **결제 없음 · 횟수 제한 없음 · 광고 없음**
- 한국어, 국내 출생지만
- 웹 · iOS · Android 동시 출시
- 수치와 시기(행성 · 하우스 · 각도 · 변곡점 · 궁합 점수)는 서버 코드가 계산하고, AI는 글만 쓴다
- 같은 차트(같은 두 사람)의 글은 한 번만 만들고, 다시 열면 같은 글이 나온다

## 사용자 흐름

스플래시 → 구글 · 애플 · 카카오 로그인 → 만 14세 이상 확인 → 출생 정보 입력 → **"내 요약 보기" 버튼 하나** → 요약 해석 → 심층 리포트 · 궁합 · 공유

- 출생 정보는 가입 때 한 번만 받는다. 이후 추가 입력은 없다 (궁합에서 상대 정보만 받는다)
- 로그인 없이 열리는 화면은 공유 페이지뿐이다

## 출시 기능

### 시작
| 기능 | 내용 |
|---|---|
| **F7 로그인 · 계정** | 구글 · 애플 · 카카오. 스플래시 직후 요구, 만 14세 이상 확인. 로그아웃, 계정 삭제 |
| **F1 출생 정보 입력** | 생년월일, 출생 시각(분 단위, "모름" 가능), 국내 시 · 군 · 구. 옛 한국 표준시 · 서머타임 변환. 가입 때 한 번 받고 설정에서 고친다 |
| **F2 출생 차트** | 내 하늘 지도(휠 · 별마다 있던 자리 · 별을 누르면 뜻과 다른 별과의 관계, 확정 시안 13), 차트 자세히(행성 · 하우스 · 각도 표). 핵심 3요소(태양 · 달 · 상승궁)는 요약 화면에 있고, 요약 화면에서 "내 차트 보기"로 연다 |

### 나
| 기능 | 내용 |
|---|---|
| **F3 요약 해석** | 버튼 하나로 바로 본다. 한 줄 총평 → 중심(태양) · 마음(달) · 첫인상과 지향(상승점 · 중천) · 힘이 몰린 곳 · 과제 → 강점 · 보완점 |
| **F4 심층 리포트** | 성격 · 관계 · 일 · 감정 · 시기 다섯 영역이 한 리포트에 함께 나온다. 영역마다 4~6문단. 완성되면 푸시 알림 |

### 시기 (심층 리포트의 다섯 번째 영역)
| 종류 | 내용 |
|---|---|
| 누구에게나 오는 마디 | 토성 사각(만 21~22세), 토성 귀환(29~30세), 천왕성 대립(42세), 두 번째 토성 귀환(58~59세). 연도는 내 차트로 계산 |
| 변화 구간 | 토성 · 천왕성 · 해왕성 · 명왕성이 내 태양 · 달 · 상승점과 합 · 사분 · 충을 이루는 기간. 사람마다 시기와 개수가 다르다 |
| 기회 구간 | 목성이 내 태양 · 달 · 상승점 · 중천 · 금성과 합 · 삼분, 목성이 5 · 7 · 11하우스를 지나는 기간. "도움이 되는 사람을 만나기 쉬운 시기", "인연이 열리기 쉬운 시기" |
| 운명적 만남 구간 | 출생 시각을 알면: 목성 · 토성 · 외행성이 내 버텍스와 합을 이루는 기간. "운명처럼 느껴지는 만남이 생기기 쉬운 시기" |
| 지금 나의 구간 | 지금 어떤 구간인지, 언제까지인지, 다음 변곡점은 언제인지를 맨 위에 보여 준다 |

- 구간은 기간(시작~끝)으로 보여 준다. 출생 시각을 모르면 상승점 구간은 뺀다
- "이 시기의 주제"만 쓰고 무슨 일이 일어난다고 쓰지 않는다

### 관계
| 기능 | 내용 |
|---|---|
| **F5 궁합** | 상대 출생 정보를 직접 입력하거나 초대 링크(7일 · 1명)를 보낸다. 결과: **나 기준 점수(0~100)** + 키워드 3개 + 한 줄 + 겹친 휠. 관계 유형(연애 · 친구 · 일)마다 점수가 다르다 |
| **궁합 랭킹** | 나 기준으로 여러 명과 1:1 매칭한 결과를 점수순으로 보여 준다. **인원 제한 없음**. 관계 유형별로 따로 본다 |
| **궁합 리포트** | 끌림 · 대화 · 갈등 · 오래가기 네 영역의 긴 글 |

- 나 기준 점수: 상대의 행성이 내 태양 · 달 · 수성 · 금성 · 화성에 만드는 각도에 가중치. 내가 본 상대 점수와 상대가 본 내 점수는 다를 수 있다
- 직접 입력한 상대의 출생 정보는 저장하지 않는다. 랭킹에는 부를 이름 · 점수 · 키워드만 저장한다

### 공유
| 카드 | 들어가는 것 |
|---|---|
| 요약 해석 카드 | 한 줄 총평 + 키워드 |
| 궁합 점수 카드 | 두 사람 이름 + 나 기준 점수 + 한 줄 ("나랑 너, 몇 점?") |
| 랭킹 카드 | "내 친구 궁합 TOP 3" |
| 다음 변곡점 카드 | "내 다음 변곡점은 2027년 봄" + 주제 한 줄 |

- 인스타 스토리(9:16) 이미지와 링크로 공유한다
- 출생 정보와 근거는 어느 카드에도 나오지 않는다. 리포트 본문은 공유하지 않는다
- 링크는 로그인 없이 열리고, "나도 보러 가기"를 누르면 가입부터 한다

## 세부 규칙 (2026-11-11 정함)

### 궁합 점수
- 상대의 행성 10개가 내 태양 · 달 · 수성 · 금성 · 화성(시각을 알면 상승점도)과 이루는 각도를 본다

| 각도 | 점수 | 허용 오차 |
|---|---|---|
| 삼분 (120°) | +8 | 7° |
| 육분 (60°) | +5 | 5° |
| 합 (0°) | +6 (토성 · 화성이 끼면 −3) | 8° |
| 사분 (90°) | −6 | 7° |
| 충 (180°) | −4 | 8° |

- 오차가 작을수록 점수를 더 준다 (정확히 맞으면 100%, 허용 오차 끝이면 0%)
- 관계 유형별 가중치: 연애는 금성-화성 · 태양-달 ×2, 친구는 수성-수성 ×2 · 달-달 ×1.5, 일은 수성-수성 ×2 · 토성-태양 ×1.5
- 합산한 값을 **40~100점**으로 바꾼다. 40점 아래는 나오지 않는다
- 60점 미만이면 "다른 결의 사이"를 붙이고 끌리는 점을 먼저 보여 준다

### 랭킹 카드
- TOP 3까지만 넣는다. 앱 안의 랭킹은 인원 제한이 없다
- 다른 사람 이름은 기본으로 이니셜로 가린다 (예: "ㅈㅇ"). 사용자가 켜면 붙인 이름을 그대로 보여 준다

### 변곡점
| 항목 | 규칙 |
|---|---|
| 나이 범위 | 만 80세까지 계산, 화면은 지금 기준 앞뒤 10년 먼저 |
| 각도 | 변화 구간은 합 · 사분 · 충, 기회 구간은 합 · 삼분, 운명적 만남 구간은 합 |
| 영역 | 구간마다 사람 · 인연(5 · 7 · 11하우스) / 일(6 · 10) / 돈(2 · 8) / 나 자신(1 · 3 · 4 · 9 · 12)을 붙인다. 시각을 모르면 행성의 뜻으로 정한다 |
| 허용 오차 | 1° 이내에 들어와 있는 기간을 한 구간으로, 역행으로 여러 번 지나가면 하나로 묶음 |
| 큰 변화 | 천왕성 · 해왕성 · 명왕성 × 태양 · 달의 합 · 충, 토성 귀환, 천왕성 대립 |
| 작은 변화 | 그 밖 (토성 통과, 상승점 대상, 사분) |

### 방향성 제시
- 놓이는 화면: 미래는 심층 리포트 "시기" 끝, 이성은 요약 해석 아래, 궁합은 궁합 결과 아래
- 심층 리포트 "관계" 영역은 "나는 사람을 어떻게 대하는 사람인가"(설명), 방향성 "이성"은 "연애에서 앞으로 해 볼 만한 것"(행동)
- 분량: 주제마다 한 줄 제목 + 해 볼 만한 것 3개

### 버텍스 · 키론
- 버텍스는 1.0.0에 넣는다. 출생 시각을 아는 사람에게만 보여 주고, 운명적 만남 구간에 쓴다
- 키론은 1.0.0에 넣지 않는다. 키론 귀환(만 50세) 변곡점도 뺀다. 1.1.0 이후에 다시 본다

## 아직 정할 것

**1.0.0**
- 앱 이름, 대표 문구, 상표 확인
- 만 14세 확인 방법 (생년월일 입력 / 카카오 연령대)
- 궁합 점수 합산값 → 40~100점 변환 구간 (표본 차트 분포를 본 뒤)

**1.1.0**
- 방향성 제시를 유료로 바꾸는 시점과 가격, 이미 만든 글을 계속 볼 수 있게 할지
- 광고: 첫 요약 해석 앞에도 둘지, 웹에서도 보여 줄지
- 투두 · 조각 · 레벨업: 조각 수, 레벨 기준, 레벨 보상, 투두 주기, 화면 경로
- 키론을 넣을지
