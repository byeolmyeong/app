# 외부 API·결제·발송 규칙

- 결제·발송 완료 판정은 HTTP 200이 아니라 응답 본문의 상태 필드로만 한다. 미확정 상태에서는 포인트·재고·발송 상태를 바꾸지 않는다.
- 외부 API 재시도는 상한을 둔다. 무한 재시도 금지. 대량 호출은 동시성·간격을 제한하고 실행 전 예상 호출 수를 사용자에게 확인한다.
- 실패·빈 응답은 캐시에 쓰지 않는다.
- 발송기가 반환형(`false`)인지 예외형(throw)인지 확인하고, 실패를 성공으로 보고하지 않는다. 결과는 `sent / skipped / failed` 셋으로 구분한다.
- 불확실 응답(timeout)의 재시도가 이중 처리(이중 환불·이중 발송)를 만들지 않도록 멱등 상태(`pending → confirmed`)를 둔다.
