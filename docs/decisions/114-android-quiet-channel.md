# 114. (1.1.0) 안드로이드 "조용한 알림" 채널 `quiet` 은 중요도 보통 · 소리 없음 · 진동 없음으로 만든다

> 상태: 활성 · 결정일 2026-11-28(앱 #167 리뷰 뒤 소유자 확인 "엉 다 해") · 결정 104 의 9(밤 9시 ~ 아침 8시에는 바로 보내되 소리 없이)와 107 의 5(공지 알림도 같은 규칙)가 "조용한 채널"까지만 정한 것을 채운다. 결정 098(HIGH 채널)은 그대로다.
> - 서버 짝: 서버 결정 057(서비스 알림의 밤 무음 — 1.1.0 이상 안드로이드에만 `channelId: "quiet"`)
> - 계획: `docs/plans/2026-11-27-1.1.0.md` 의 A1-5

## 맥락
- 서버는 밤 9시 ~ 아침 8시(한국 시각)에 공지 · 궁합 알림을 바로 보내되, 1.1.0 이상 안드로이드 기기에는 채널 `quiet` 를 싣는다(서버 057). 채널이 없는 기기에 채널 id 를 실으면 알림이 제대로 보이지 않는다.
- 안드로이드는 앱이 한 번 만든 채널의 소리 · 진동을 다시 바꿀 수 없고, 중요도는 낮출 수만 있다(높일 수 없다). 그래서 출시 전에 값을 정해야 한다.
- 지금 기본 채널은 중요도 HIGH(위에서 내려오는 배너 · 소리, 결정 098)다.

## 결정
1. 채널 id `quiet`, 이름 "조용한 알림"(휴대폰 설정 › 알림에 보이는 이름 — `strings.push.quietChannel`).
2. 중요도 **보통(DEFAULT)**: 상태 표시줄 · 알림 칸 · 잠금 화면에 보이고, 위에서 내려오는 배너는 없다.
3. **소리 없음 · 진동 없음**.
4. 기본 HIGH 채널과 함께, 권한을 물을 때와 기기를 서버에 등록하기 직전(1.0.x 에서 업데이트한 기기 — 권한 창이 다시 뜨지 않는다)에 만든다. 채널을 못 만들면 등록하지 않는다(서버가 1.1.0 으로 기록한 기기에는 채널이 늘 있다). iOS · 웹은 만들지 않는다.

## 근거
- "자는 사람을 깨우지 않되 알림은 놓치지 않게"(104 의 9): 보통은 알림 칸에 남고, 낮음(LOW)은 안드로이드 10 이상에서 "무음" 묶음으로 접혀 잘 안 보인다.
- 중요도는 나중에 낮출 수만 있으므로 보통으로 시작하는 쪽이 고칠 여지가 남는다.

## 대안
- 중요도 낮음(LOW): 더 조용하지만 접힌 묶음으로 들어가 공지 · 궁합 알림을 놓치기 쉽다.
- 밤에도 기본 채널(HIGH)에 소리만 빼기: 안드로이드 8 이상은 채널의 소리가 우선이라 메시지마다 소리를 뺄 수 없다.

## 결과 · 재검토 조건
- 이 값은 출시 뒤 바꿀 수 없다(바꾸려면 새 채널 id 를 만들고 서버의 채널 id 도 같이 바꾼다).
- 실기기(안드로이드)에서 밤 알림이 소리 · 진동 없이 알림 칸에 보이는지 1.1.0 테스트 빌드에서 확인한다.
- 원본: 앱 #167 리뷰 · 소유자 2026-11-28 "엉 다 해"(채널 값 제안을 그대로 받아들임).
