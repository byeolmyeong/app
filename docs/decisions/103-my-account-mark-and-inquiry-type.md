## 맥락
- 내 정보의 연결된 계정 줄은 공급자 표시 옆에 가린 이메일(예: dawn****@kakao.com)을 보인다(056 · 087).
- 점신 계정관리는 "SNS 연동 계정"에 공급자만 보인다.
- 새 문의의 종류 칩 위 이름은 "어떤 문의예요?"다(`strings.inquiry.categoryLabel`). 아래 칸 이름 "내용"과 말투가 다르다.

## 결정
1. **연결된 계정 줄**
   - 왼쪽에 "연결된 계정", 오른쪽에 공급자 마크만 둔다. 카카오는 노란 원 안의 말풍선이고, Apple · Google 은 각 마크다.
   - 글자와 이메일은 보이지 않는다.
   - 마크에는 화면 읽기 이름을 붙인다(`strings.my.account.providers` 의 카카오 · Apple · Google 그대로).
   - 개발용(DEV) 계정은 마크가 없으니 이름 글자를 그대로 둔다.
   - 앱의 이메일 가리기(`src/features/my/mask-email.ts`)와 그 테스트는 쓰는 곳이 없어지므로 구현 때 지운다.
   - 서버 응답의 이메일은 그대로 둔다(어드민 · 문의 답변이 쓴다). 앱이 읽지 않을 뿐이다.
2. **새 문의의 종류 칸 이름**: "어떤 문의예요?"를 "유형"으로 바꾼다(`strings.inquiry.categoryLabel`). 칩(오류 · 제안 · 계정 · 기타)은 그대로다.
3. **공유 시트의 아래 버튼을 나란히 둔다**(2026-11-27 추가, 소유자 "다른 카드들이랑 공유하기 카드 디자인이 다른데 둘 중 하나로 통일 시키는 게 좋지 않을까??" → 궁합 시안 11 을 보고 "이게 난 더 좋긴한 것 같은데").
   - 왼쪽 보조 "이미지 저장", 오른쪽 주 "인스타그램 스토리"(1 : 1.4, 높이 56). 위아래로 쌓던 것과 "인스타그램 스토리 공유"(`strings.share` 의 story) 글을 바꾼다.
   - 보조 버튼 바탕은 #2A2B33(시트 바탕 #16171D 위에서 보이게). 미리보기 틀(209×372, 테두리)은 그대로다.
   - 앱은 공용 시트(`src/features/share/share-entry.tsx`) 하나라 모든 공유(오늘의 하늘 · 내 별명 · 나 탭 · 시기 · 궁합)가 같이 바뀐다. 웹은 "이미지 저장" 하나 그대로다(결정 053 의 1).
   - 시안: 11-6 · 12-4 · 12-13 · 14-5 를 고쳤고, 궁합 11 · 11-2 가 같은 모양이다. 구현 때 피그마 v1.0.0 보드도 고친다.

## 근거
- 화면에 개인정보를 덜 보인다. 화면을 공유하거나 스크린숏을 찍어도 이메일이 남지 않는다.
- 공급자 마크는 글자 없이도 알아본다. 줄이 짧아진다.
- "유형"은 아래 칸 이름 "내용"과 같은 꼴이라, 칸 이름이 짧고 고르게 읽힌다.

## 대안
- 공급자 이름 글자("카카오"): 한 번 그렸으나 소유자가 "마크만 있어도"라고 했다.
- 가린 이메일 그대로: 소유자가 "이메일 없애고"라고 했다.
- 점신처럼 "SNS 연동 계정": 지금 줄 이름 "연결된 계정"이 더 쉬운 말이라 바꾸지 않았다.

## 결과 · 재검토 조건
- 1.1.0 앱 할 일:
  - 내 정보 연결된 계정 줄을 바꾼다.
  - `strings.inquiry.categoryLabel` 을 바꾼다.
  - `mask-email` 을 지우고 테스트를 고친다.
- 공급자 마크는 각 브랜드 가이드(카카오 심볼 · Apple · Google)의 색과 모양을 따른다. 로그인 버튼 가이드(캔버스 메모 "소셜 로그인 버튼")와 같은 원본을 쓴다.
- 피그마 16-1 · 16-8 은 앱에 반영할 때 바꾼다.
