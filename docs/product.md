# 제품 스펙

> 상태: 활성 · 기준 2026-11-10

## 이름
- 앱 이름은 "별명"이다. 닉네임(別名)이라는 익숙한 뜻에 "별이 정해 준 명(命)"을 겹친 말장난이고, 한글로만 표기한다. 대표 문구: "별이 붙여 준 나의 별명".
- 일상어와 같아 검색에서 묻히므로 스토어 표기에는 부제를 붙인다(예: "별명 - 나를 읽는 점성술"). [확인 필요] 상표·스토어 동명 앱 여부.
- 저장소: 앱 `byeolmyeong-app`, 서버 `byeolmyeong-api`.

## 한 줄
생년월일·시각·장소로 서양 점성술 출생 차트를 계산하고, AI 가 점성술 용어 없이 "나를 설명해 주는 글"로 풀어 주는 한국어 서비스. 심층 리포트와 궁합을 앱에서 건당 판매한다.

## 타겟·문제
- 타겟: 한국어 사용자 중 MBTI·별자리 같은 자기 이해 콘텐츠를 즐기는 20~30대.
- 문제 1: 국내 운세 앱(점신·포스텔러)은 사주 중심이라 서양 점성술을 깊게 다루는 한국어 서비스가 비어 있다.
- 문제 2: 기존 점성술 앱의 해석은 고정 문구 조합이라 "누구에게나 하는 말"로 읽힌다. 차트 전체를 엮은 개인화 해석이 없다.
- 문제 3: 하우스·애스펙트 같은 용어가 진입 장벽이다.

## 컨셉: 심리 분석형
- 해석 본문에 점성술 용어를 쓰지 않는다. "금성이 전갈자리 7하우스" 대신 "관계에서 깊이를 확인해야 마음을 여는 사람"처럼 쓴다.
- 근거가 궁금한 사용자는 문단마다 "왜 이렇게 나왔나"를 펼쳐 차트 요소(행성·별자리·하우스)를 볼 수 있다.
- 말투는 단정하지 않는 관찰형이다. 미래 예언·건강·투자 단정은 하지 않는다(규칙: docs/golden-rules.md 프로젝트 규칙).
- 벤치마킹: 해석 말투와 깊이는 The Pattern, 공유 구조는 Co-Star, 한국 결제 구조와 가격대는 포스텔러.

## 버전별 범위
- 1.0.0 — 무료 핵심 기능: 출생 정보 입력, 차트, 요약 해석, 궁합 키워드, 공유, 구글·애플 로그인. 웹과 스토어 앱 동시 출시. 기능 명세: docs/release-1.0.0.md
- 1.1.0 — 인앱결제와 유료 리포트: 심층 리포트(성격·관계·일·감정 영역별), 궁합 리포트.
- 1.2.0 이후 — 오늘의 운세·트랜싯·푸시 알림.
- 계획 없음 — 사주·타로·베다 점성술, 점성가 상담 연결, 커뮤니티.

## 플랫폼·결제
- 코드 하나(Expo)로 웹·iOS·Android 를 만든다. 결정: docs/decisions/001-expo-single-codebase.md
- 서버는 Spring Boot 로 직접 만든다. 결정: docs/decisions/004-spring-backend.md
- 결제는 1.1.0 에서 붙인다. 스토어 인앱결제만, 건당(소모성) 상품이다. 웹에서는 결제하지 않고 앱으로 유도한다. 결정: docs/decisions/002-iap-only-per-report.md
- 로그인은 구글·애플만, 해석을 받을 때 요구한다. 결정: docs/decisions/005-google-apple-login.md
- 가격: [확인 필요] 심층 리포트·궁합 건당 가격. 포스텔러 가격대를 확인한 뒤 정한다.

## 성공 지표 (출시 후 4주)
- 차트 생성 완료율(입력 시작 → 차트 화면): 70% 이상.
- 요약 해석을 끝까지 읽은 비율: 50% 이상.
- 차트를 본 사용자 중 로그인해 요약 해석까지 본 비율: 40% 이상. [확인 필요] 목표치는 추정이며 근거 데이터가 없다.
- (1.1.0 이후) 첫 결제 전환율: 3% 이상. [확인 필요] 추정.
- 공유 링크로 들어온 방문자의 차트 생성 비율: 30% 이상.

## 왜 이 범위인가
- 궁합 키워드를 1.0.0 에 넣은 이유: 혼자 보는 해석보다 다시 쓸 이유가 되고, 1.1.0 궁합 리포트의 입구다.
- 오늘의 운세를 뒤로 미룬 이유: 건당 결제 모델에서는 매일 새 콘텐츠가 매출과 직접 연결되지 않고, 구현 범위가 가장 크다.
- 유료 리포트를 1.0.0 에서 무료로 풀지 않는 이유: 나중에 유료로 돌리기 어렵고 AI 비용이 사용량만큼 나간다.
