# 제품 스펙

> 상태: 활성 · 기준 2026-11-11 · 2026-11-11 변경의 출처: docs/raw/2026-11-11-memo-roadmap-1.0.0-1.1.0.md, docs/raw/2026-11-11-session-planning-1.0.0.md

## 이름
- 앱 이름 "별명"은 가칭이다. 받침이 연달아 와 잘 안 읽히고 먼저 '닉네임'으로 읽혀서 바꾸기로 했다. 새 이름은 브랜딩 단계에서 정한다. 결정: docs/decisions/013-rename-app.md
- 새 이름 기준: 받침이 연달아 오지 않는다, 별(점성술)이 보인다, 쉽게 읽힌다. [확인 필요] 상표·스토어 동명 앱·도메인.
- 저장소: 앱 `byeolmyeong-app`, 서버 `byeolmyeong-api`. 저장소 이름은 지금 바꾸지 않는다.

## 한 줄
생년월일·시각·장소로 서양 점성술 출생 차트를 계산하고, AI 가 점성술 용어 없이 "나를 설명해 주는 글"로 풀어 주는 한국어 서비스. 1.0.0 은 전부 무료이고, 수익 모델은 1.1.0 에서 붙인다.

포지셔닝 한 문장: **점성술 몰라도 읽히는 나, 나의 사람들, 나의 타이밍**

## 타겟·문제
- 핵심 타겟: 점성술은 잘 모르는 20대 초반~30대 초반(여성 중심). 연애·궁합이 궁금하고, 이직·이별·독립 같은 전환기에 "나 지금 어떤 시기야?"가 궁금하다. 오래 쓰고 깊게 본다.
- 확산 타겟: 10대 후반(만 14세 이상). 예쁜 결과를 인스타 스토리에 올리고, 그걸 본 친구들이 따라 들어온다. 친구 궁합·진로와 미래·내 변곡점이 궁금하다.
- 기능은 타겟별로 나누지 않는다. 말투·표현이 부딪히면 핵심 타겟을 따른다. 가입은 만 14세 이상만 받는다(결정: docs/decisions/009-signup-first-kakao-age14.md).
- 문제 1: 국내 운세 앱(점신·포스텔러)은 사주 중심이라 서양 점성술을 깊게 다루는 한국어 서비스가 비어 있다.
- 문제 2: 기존 점성술 앱의 해석은 고정 문구 조합이라 "누구에게나 하는 말"로 읽힌다. 차트 전체를 엮은 개인화 해석이 없다.
- 문제 3: 하우스·애스펙트 같은 용어가 진입 장벽이다.

## 컨셉: 심리 분석형
- 해석 본문에 점성술 용어를 쓰지 않는다. "금성이 전갈자리 7하우스" 대신 "관계에서 깊이를 확인해야 마음을 여는 사람"처럼 쓴다.
- 근거가 궁금한 사용자는 문단마다 "왜 이렇게 나왔나"를 펼쳐 차트 요소(행성·별자리·하우스)를 볼 수 있다.
- 말투는 단정하지 않는 관찰형이다. 미래 예언·건강·투자 단정은 하지 않는다(규칙: docs/golden-rules.md 프로젝트 규칙).
- 벤치마킹: 해석 말투와 깊이는 The Pattern, 공유 구조는 Co-Star, 한국 결제 구조와 가격대는 포스텔러.

## 버전별 범위
- 1.0.0 — 무료 핵심 기능(횟수 제한 없음, 광고 없음): 스플래시 직후 구글·애플·카카오 로그인(만 14세 이상), 출생 정보 입력, 차트, 요약 해석, 심층 리포트(외행성 통과 구간을 포함한 변곡점), 궁합(나 기준 점수·랭킹), 스토리 공유 카드. 웹과 스토어 앱 동시 출시. 기능 명세: docs/release-1.0.0.md
  - 방향성 제시(F10)는 1.0.0 에 전체 무료로 주고 추후 같은 기능을 유료로 바꾼다. 심층 리포트와 궁합 리포트는 계속 무료다. 결정: docs/decisions/014-todo-pieces-to-1.1.0-free-first.md
- 1.1.0 — 결제와 친구창:
  - 인앱결제: 1.1.0 의 유료 상품은 방향성 제시와 990원 광고 제거다. 심층 리포트와 궁합 리포트는 유료로 바꾸지 않는다. [확인 필요] 방향성 제시를 유료로 바꾸는 시점과 가격. 결정: docs/decisions/014-todo-pieces-to-1.1.0-free-first.md
  - 방향성 제시 유료화(1.0.0 과 같은 기능, 건당 구매), 990원 광고 제거 상품. 광고는 1.1.0 부터 결과를 보기 전에 15초 나오고, 같은 결과를 다시 열 때는 나오지 않는다. 결정: docs/decisions/008-ads-and-ad-removal.md, docs/decisions/014-todo-pieces-to-1.1.0-free-first.md, docs/decisions/015-ad-before-results-15s.md
  - 친구창: 친구 추가, 채팅, 같이 볼 수 있는 방. 결정: docs/decisions/007-friends-chat-shared-room.md
  - 투두·조각·레벨업: AI 가 방향성 제시에서 뽑은 투두를 완료하면 조각을 받고, 조각이 쌓이면 레벨이 오른다. 대표 문구 "조각을 모은다". 1.0.0 에서 옮겨 왔다. 결정: docs/decisions/014-todo-pieces-to-1.1.0-free-first.md
  - 그룹 궁합: 친구끼리 3~5명이 서로를 비교한다. 1.0.0 의 궁합은 나 기준으로 여러 명과 1:1 매칭하고 인원 제한이 없다.
- 1.2.0 이후 — 영어와 해외 출생지, 오늘의 운세·매일·매주 바뀌는 트랜싯·푸시 알림. 외행성 통과 구간은 1.0.0 에 넣었다(결정: docs/decisions/012-transit-intervals-in-1.0.0.md).
- 계획 없음 — 사주·타로·베다 점성술, 점성가 상담 연결, 모르는 사람끼리 만나는 공개 커뮤니티(게시판·피드).

## 플랫폼·결제
- 코드 하나(Expo)로 웹·iOS·Android 를 만든다. 결정: docs/decisions/001-expo-single-codebase.md
- 서버는 Spring Boot 로 직접 만든다. 결정: docs/decisions/004-spring-backend.md
- 결제는 1.1.0 에서 붙인다. 스토어 인앱결제만 쓴다. 웹에서는 결제하지 않고 앱으로 유도한다. 결정: docs/decisions/002-iap-only-per-report.md
- 상품은 건당(소모성) 방향성 제시와, 한 번 사면 계속 가는(비소모성) 990원 광고 제거다. 광고는 1.1.0 부터 결과를 보기 전에 15초 나온다(1.0.0 에는 광고가 없다). 결정: docs/decisions/008-ads-and-ad-removal.md, docs/decisions/014-todo-pieces-to-1.1.0-free-first.md, docs/decisions/015-ad-before-results-15s.md
- 로그인은 구글·애플·카카오이고, 스플래시 직후 요구하며 만 14세 이상인지 확인한다. 결정: docs/decisions/009-signup-first-kakao-age14.md (005 를 대체)
- 가격: 광고 제거 990원. [확인 필요] 방향성 제시의 건당 가격. 포스텔러 가격대를 확인한 뒤 정한다.

## 성공 지표 (출시 후 4주)
- 가입 완료율(스플래시 → 가입 완료): [확인 필요] 목표치. 가입이 첫 화면으로 왔으므로 가장 먼저 본다.
- 차트 생성 완료율(입력 시작 → 차트 화면): 70% 이상.
- 요약 해석을 끝까지 읽은 비율: 50% 이상.
- 가입한 사용자 중 요약 해석까지 본 비율: 40% 이상. [확인 필요] 목표치는 추정이며 근거 데이터가 없다.
- 공유 카드(요약 해석·궁합 점수·랭킹·다음 변곡점)를 올린 사용자 비율: [확인 필요] 목표치.
- (1.1.0 이후) 광고 시청 완료율과 광고 앞 이탈률(특히 첫 요약 해석 앞): [확인 필요] 목표치. 결정: docs/decisions/015-ad-before-results-15s.md
- (1.1.0 이후) 첫 결제 전환율: 3% 이상. [확인 필요] 추정.
- 공유 링크로 들어온 방문자의 차트 생성 비율: 30% 이상.

## 왜 이 범위인가
- 궁합 점수·랭킹을 1.0.0 에 넣은 이유: 혼자 보는 해석보다 다시 쓸 이유가 되고, 숫자와 순위는 친구끼리 비교해 스토리에 올리기 쉬워 확산 타겟에 강하다. 결정: docs/decisions/010-synastry-score-ranking-share-cards.md
- 오늘의 운세를 뒤로 미룬 이유: 매일 새 콘텐츠는 AI 비용이 계속 들고, 구현 범위가 가장 크다.
- 투두·조각·레벨업을 1.1.0 으로 옮긴 이유: 조각 수·레벨 기준·보상·투두 주기가 정해지지 않았고, 방향성 제시가 먼저 쓰여야 투두의 모양이 정해진다. 1.0.0 의 재방문은 궁합 랭킹과 "지금 나의 구간"이 맡는다. 결정: docs/decisions/014-todo-pieces-to-1.1.0-free-first.md
- 친구창을 1.1.0 으로 둔 이유: 채팅은 신고·차단과 실시간 서버가 따라오는 큰 범위다. 핵심 기능이 선 뒤에 붙인다.
- 1.0.0 에 횟수 제한을 두지 않는 이유: 랭킹과 조각은 궁합을 여러 번 봐야 쌓이고, 같은 글은 다시 생성하지 않아 AI 비용은 새 차트·새 상대 수만큼만 든다. 나중에 유료로 돌리기 어렵다는 위험은 1.1.0 유료 범위를 정할 때 다룬다. 결정: docs/decisions/011-no-usage-limits-in-1.0.0.md
- 외행성 통과 구간을 1.0.0 에 넣은 이유: 정해진 마디만으로는 나이가 같으면 변곡점도 같아 보인다. 사람마다 다른 구간이 "나만의 변곡점"이 된다. 결정: docs/decisions/012-transit-intervals-in-1.0.0.md
