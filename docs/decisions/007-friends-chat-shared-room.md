# 007. 1.1.0 에 친구창(친구 추가·채팅·같이 보는 방)을 넣는다

> 상태: 활성 · 결정일 2026-11-11 · 출처: docs/raw/2026-11-11-memo-roadmap-1.0.0-1.1.0.md

## 맥락
docs/product.md 는 커뮤니티를 "계획 없음"으로 두었다. 1.0.0 에서 사람과 사람을 잇는 것은 궁합 초대 링크 하나뿐이고, 결과를 본 뒤에는 둘이 함께 할 일이 없다. 사용자가 1.1.0 에 친구창을 넣기로 정했다.

## 결정
1.1.0 에 친구창을 넣는다. 구성은 세 가지다.
- 친구 추가(친추).
- 친구와의 채팅.
- 같이 볼 수 있는 방: 친구와 결과를 함께 보는 공간.

모르는 사람끼리 만나는 공개 커뮤니티(게시판·피드)는 계속 "계획 없음"이다. 이 결정은 아는 사람끼리의 기능만 다룬다.

## 근거
- 궁합은 이미 두 사람을 잇는다. 친구로 남아 있으면 다시 들어올 이유가 생긴다.
- 사용자가 정했다(출처 메모).

## 대안
- 지금처럼 초대 링크만 — 결과를 한 번 보고 끝난다.
- 공개 커뮤니티 — 신고·차단·운영 부담이 크다. 계획 없음을 유지한다.

## 결과·재검토 조건
- 채팅이 들어가면 스토어 심사가 신고·차단 기능을 요구한다. 1.1.0 범위에 함께 넣어야 한다.
- 출생 정보는 친구에게도 보여 주지 않는다(docs/golden-rules.md 프로젝트 규칙, docs/release-1.0.0.md F5 와 같은 기준).
- [확인 필요] 친구를 추가하는 방법(초대 링크·아이디 검색·연락처), 방에서 함께 보는 대상(궁합 결과·리포트·차트), 방의 인원, 채팅 보관 기간.
- 서버에 실시간 통신이 필요해진다. 방식은 서버 저장소에서 새 ADR 로 정한다.
