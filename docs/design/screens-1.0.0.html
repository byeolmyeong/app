1.0.0 디자인 시안

방향은 "도장과 책력"이다. 흰 종이에 검은 글씨, 색은 인주 빨강 하나. 상자와 그림자 대신 가는 선과 표로 나눈다. 차트 수치는 옛 달력의 표처럼 읽힌다. 글꼴은 Pretendard 하나. 화면 속 인물과 글은 예시다.

숫자는 폭이 같은 숫자로 맞춰 표에서 세로줄이 맞는다.

01

입력과 차트

홈이 곧 입력 화면이다. 차트까지는 로그인 없이 보고, 글을 받을 때 로그인한다. 차트 아래의 표는 전체 수치로 이어진다.

출생 정보 입력 (홈)소개나 가입 화면을 앞에 두지 않는다.
차트로그인 없이 본다. 주 버튼은 "내 별명 읽기" 하나.
차트 자세히행성·하우스·각도의 전체 수치. 점성술을 아는 사람을 위한 표.
로그인화면을 옮기지 않고 아래에서 올린다. 구글·애플 두 가지.
02

내 별명 (요약 해석)

본문은 쉬운 말로 쓰고, 문단 머리에 근거가 된 차트 요소를 작게 늘 보여 준다. 순서는 중심과 마음 → 첫인상과 지향 → 힘이 몰린 곳 → 과제 → 한 줄 총평.

글을 쓰는 중진행 상태를 보여 주고 화면을 떠나도 된다.
내 별명맨 위가 한 줄 총평이다. 도장은 글이 완성됐다는 표시.
이어지는 문단과 마무리강점과 보완점을 나란히 두고, 심층 리포트와 공유로 이어진다.
03

심층 리포트

성격·관계·일·감정·시기 다섯 영역. 계정당 1편 무료이고 완성되면 알림으로 알린다. "시기"는 인생의 변곡점을 연도로 계산해 보여 준다.

리포트 받기무료 1편이라는 점과 걸리는 시간을 먼저 알린다.
알림 허용 요청첫 실행 때가 아니라 리포트를 요청한 직후에 묻는다.
리포트 · 관계위쪽 탭으로 영역을 옮긴다. 근거 표시는 요약 해석과 같다.
리포트 · 시기연도는 코드가 계산하고 글은 "이 시기의 주제"로만 쓴다. 미래를 단정하지 않는다.
04

궁합

상대 정보를 직접 넣거나 초대 링크를 보낸다. 결과에 점수는 없고 낱말 세 개와 한 줄 요약이 있다.

궁합 시작두 가지 방법과 지난 궁합 목록.
초대 링크 보내기상대가 수락하면 알림으로 알린다.
초대 수락 (받은 사람)무엇이 상대에게 보이고 무엇이 안 보이는지 먼저 밝힌다.
궁합 결과검은 점은 나, 빈 점은 상대.
05

공유 페이지 (웹)

로그인 없이 열린다. 글만 있고 생년월일·시각·출생지는 나오지 않는다.

내 별명 공유버튼은 "내 별명 보러 가기" 하나.
궁합 결과 공유두 사람의 부를 이름만 나온다.
06

설정

계정 삭제는 설정 안에서 바로 시작할 수 있다.

설정알림, 안내 문서, 로그아웃, 계정 삭제.
계정 삭제 확인무엇이 지워지는지 적고 한 번 더 묻는다.
