# 063. (1.1.0) 궁합은 별 지도 + 전체 순위 한 화면이고, 궁합 하나는 한 번에 다 만들며, 초대는 "내 궁합 링크" 하나다

> 상태: **제안 — 1.1.0 계획 때 확정**(시안은 소유자가 정했다, 1.0.0 에는 넣지 않는다 — 결정 055) · 결정일 2026-11-20(소유자 시안 C + ②안, "한 사람들 다 보이게", "나에 대한 링크를 복사해서 여러 사람들이 들어와서 직접 입력", "앱이 깔려있다면 앱으로, 없으면 웹으로", "60점 이하라고 간단하게 하는 게 아니라 그냥 있는 거 다", "모달로 나오는 게 맞지") · 확정되면 결정 010 · 020 · 022 · 026 의 궁합 부분과 release F5 · F6 · F10 의 궁합을 대체한다 · 시안: 캔버스 "궁합 (1.1.0)" 15 ~ 15-11 · 피그마 "궁합 (1.1.0)"

## 결정(시안대로)
1. **궁합 탭(15)**: 나를 가운데 둔 별 지도(가까울수록 높은 점수 · 테두리 색 = 관계) + 전체 순위. 관계(연애 · 친구 · 일 · 가족)로 화면을 나누지 않는다 — 관계는 새 궁합을 넣을 때 한 번 고르고 점수 가중치 · 글 말투에만 쓴다. 처음(0명)은 빈 하늘 + 직접 입력 · 링크 보내기.
2. **궁합 하나는 한 번에 다 만든다**: 보는 중(15-3) → 결과(15-4) 한 화면에 점수 + 한 줄 · 키워드 · 네 영역(끌림 · 대화 · 갈등 · 오래가기) · 이 사이의 작은 실천. 따로 받는 궁합 리포트 · 방향성 화면은 없다. 60점 아래도 모두 보인다. 실패는 결정 061 틀(다시 보기 · 나중에 하기).
3. **직접 입력한 상대 출생 정보는 저장하지 않는다**(남의 개인정보). 결과 글만 남는다.
4. **초대 = 내 궁합 링크 하나**: 여러 사람이 같은 링크로 들어와 각자 출생 정보 · 사이를 넣는다. "다시 만들기" 면 옛 링크가 닫힌다. 같은 주소가 앱이 있으면 앱(유니버설 링크 · 앱 링크), 없으면 웹(로그인 → 출생 정보 → 사이 → 결과). 웹 화면에 "앱으로 보기"(기기 스토어로). 닫힌 링크는 "별명 앱 받기" + "웹에서 시작하기".
5. **보내기**: 주 버튼 카카오톡 공유(메시지 카드 — 로그인과 같은 카카오 앱 키), 그 위 "다른 곳으로 보내기"(시스템 공유), 링크 칸 옆 복사 · 다시 만들기. 카톡 안 브라우저는 유니버설 링크가 잘 안 열려 웹이 먼저 뜰 수 있다 → "앱으로 보기" 로 넘긴다.
6. **공유 카드**: "내 하늘" 카드에 궁합 본 사람 모두(첫 자음 + 점수, 관계 색 없음, 이름 가리기 기본 켬). 결과 카드는 점수 · 한 줄.
7. **지우기**: 결과 머리 ⋯ 메뉴의 "이 궁합 지우기"(그냥 글자) → 가운데 확인 창.

## 결과·재검토 조건
- 1.1.0 계획에서 서버 계약(링크 · 웹 진입 · 카카오 공유 · 점수 가중치)과 함께 확정하고 상태를 활성으로 바꾼다.
