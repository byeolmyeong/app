# 040. 제품 분석은 앰플리튜드와 파이어베이스 애널리틱스(GA4)를 1.0.0 부터 같이 쓰고, 출생 정보·주소 속 식별자는 보내지 않는다

> 상태: 활성 · 결정일 2026-11-19(소유자) · 계획: docs/plans/2026-11-19-product-analytics.md · 서버 쪽: 서버 저장소 `docs/architecture.md` 의 `GET /auth/session`(분석용 id)

## 맥락
- docs/product.md "성공 지표"에 출시 후 4주 동안 볼 숫자가 있다: 가입 완료율, 차트 생성 완료율, 요약 해석을 끝까지 읽은 비율, 공유 카드를 올린 비율, 공유 링크 방문자의 차트 생성 비율. 이 숫자를 잴 도구가 정해져 있지 않았다.
- 푸시 알림(F8) 때문에 파이어베이스 프로젝트는 1.0.0 에 어차피 만든다(docs/release-1.0.0.md "사용자만 할 수 있는 준비").
- 공유 링크(웹 화면 `/s/…`)·초대 링크의 식별자는 그 자체로 열쇠이고, 카카오 웹 로그인이 돌아오는 주소에는 인증 코드(`?code=`)가 있다. 분석 도구는 기본으로 페이지 주소를 통째로 보낸다.
- 소유자 결정(2026-11-19): 앰플리튜드를 쓰고, 파이어베이스를 1.0.0 에 넣으니 GA4 도 같이. 사용자 구분은 서버 계정 기반, 처리방침에 적고 바로 수집, 앱 + 웹, 운영·스테이징 분리.

## 결정
1. **두 도구를 같이 쓰고 역할을 나눈다.** 앰플리튜드는 퍼널·리텐션(성공 지표), GA4 는 유입 경로와 1.1.0 의 광고 쪽. 앱은 이벤트 하나를 두 곳에 같이 보낸다. 화면 코드는 SDK 를 직접 부르지 않고 `src/lib/analytics/` 만 부른다.
2. **이벤트는 계획의 "이벤트" 표 11개가 단일 출처다.** 더하려면 표부터 고친다. 속성 값은 정해진 값 목록·참거짓만 받는다(자유 글자를 받는 자리를 두지 않는다).
3. **보내지 않는 것**: 출생 정보(날짜·시각·곳) · 이름 · 해석 글 · 차트 값 · 공유 id · 초대 id · 인증 코드 · 이메일 · 소셜 계정 id. 자동 페이지·화면 수집을 끄고, 화면 이름은 경로 패턴(`/s/[shareId]`)으로만 보낸다.
4. **사용자 구분**: 가입 전에는 기기 익명 id, 로그인하면 서버가 주는 분석용 id(계정 id 의 되돌릴 수 없는 해시)로 이어 붙인다. 로그아웃·계정 삭제 뒤에는 초기화한다.
5. **광고 식별자(IDFA·AAID)와 IP 저장을 끈다.** 그래서 iOS 추적 허용 창을 띄우지 않는다.
6. **환경**: 앰플리튜드·파이어베이스 모두 스테이징·운영 프로젝트를 따로 둔다. 키가 없는 로컬 개발은 아무것도 보내지 않고 콘솔에만 찍는다. 네이티브 파이어베이스 설정 파일은 커밋하지 않고 EAS 파일 환경 변수로 넣는다.
7. **동의**: 따로 동의 창을 띄우지 않고 개인정보 처리방침에 수집 항목·목적·처리 위탁/국외 이전(앰플리튜드·구글)·보관 기간을 적는다. 스토어 개인정보 항목도 고친다. 문안은 소유자가 확정한다.

## 근거
- 성공 지표가 전부 단계별 퍼널과 "끝까지 읽음" 같은 행동 비율이다. 앰플리튜드는 이 화면이 기본으로 있고 사용자가 적어도 숫자를 가리지 않는다. GA4 는 같은 분석을 탐색 화면에서 직접 짜야 하고, 사용자가 적으면 일부 숫자를 가린다.
- GA4 는 무료이고 파이어베이스 프로젝트를 같이 쓰며, 광고(1.1.0, 결정 015)를 붙일 때 유입·광고 성과를 보기 좋다.
- 속성 값을 값 목록으로만 받으면 출생 정보가 실수로 실려 갈 길이 구조적으로 없다(docs/golden-rules.md 프로젝트 규칙).

## 무료 한도 (변동 수치의 단일 출처 — 2026-11-19 확인)
- 앰플리튜드 무료 요금: 월 200만 이벤트(2026 년에 1,000만에서 줄었다). 출처: https://amplitude.com/docs/en/pricing
- GA4: 무료.
- 넘을 것 같으면 `screen_viewed` 를 먼저 줄인다.

## 대안
- GA4 만 — 무료이고 하나로 끝나지만, 퍼널·리텐션을 직접 짜야 하고 출시 초기의 적은 숫자를 가린다.
- 앰플리튜드만 — 하나로 단순하지만, 파이어베이스를 어차피 넣으면서 유입·광고 쪽 도구를 나중에 다시 붙이게 된다.
- PostHog — 화면 녹화·기능 플래그까지 되지만 무료 이벤트가 더 적고(월 100만), 소유자가 앰플리튜드를 골랐다.
- 첫 실행 때 동의 받기 — 가장 보수적이지만 첫 화면에 창이 늘고 가입 퍼널 숫자가 빈다.

## 결과·재검토 조건
- 네이티브 파이어베이스 모듈이 들어와 Expo Go 로는 파이어베이스를 시험할 수 없다(소셜 로그인 때문에 이미 개발 빌드를 쓴다, 결정 034).
- 서버 `GET /auth/session` 이 204 에서 200(`{ analyticsId }`)으로 바뀐다. 앱은 둘 다 받게 먼저 고친다.
- 계정을 지워도 분석 도구에는 이벤트가 남는다. 계정이 지워지면 분석용 id 가 사람과 이어지지 않지만, 보관 기간과 삭제 요청 방식은 처리방침을 정할 때 다시 본다.
- 1.1.0 광고·결제 이벤트를 붙일 때 표를 다시 본다. 광고 식별자를 켜야 하면 iOS 추적 허용 창과 함께 새 결정을 쓴다.
