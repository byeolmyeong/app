# 013. 앱 이름 "별명"을 바꾼다 (새 이름은 브랜딩에서 정한다)

> 상태: 활성 · 결정일 2026-11-11 · 출처: docs/raw/2026-11-11-session-planning-1.0.0.md

## 맥락
docs/product.md 는 앱 이름을 "별명"으로 정했다. 주변에 보여 주니 받침 있는 글자가 연달아 와서(별·명) 한 번에 읽히지 않고, 먼저 '닉네임'으로 읽혀 점성술 앱이라는 게 보이지 않는다는 의견이 나왔다.

## 결정
- 앱 이름을 바꾼다. 새 이름은 타깃과 기능을 정리한 뒤 브랜딩 단계에서 정한다.
- 그때까지 문서의 "별명"은 가칭으로 본다. 기능 이름 "내 별명"(요약 해석)도 새 이름에 맞춰 바뀐다.
- 저장소 이름(`byeolmyeong-app`·`byeolmyeong-api`)은 지금 바꾸지 않는다.

## 근거
- "점성술 몰라도 읽힌다"가 핵심인데 이름부터 설명이 필요하다.
- 일상어라 검색에서 묻히고 상표 확보도 불확실하다.

## 대안
- "별명" 유지 + 스토어 부제로 보완 — 읽기 어렵다는 문제가 남는다.

## 결과·재검토 조건
- 새 이름 기준: 받침이 연달아 오지 않는다, 별(점성술)이 보인다, 쉽게 읽힌다.
- [확인 필요] 새 이름의 상표(9류 앱·45류 점성/운세)·스토어 동명 앱·도메인 확인.
- 이름이 정해지면 화면 문구(`src/content/strings.ts`)·CLAUDE.md·product.md 의 이름을 한 번에 바꾼다.
