# 1.0.0 기획안

> 기준 2026-11-11 · 원본: `byeolmyeong-app/docs/release-1.0.0.md`, `docs/product.md`. 오늘 논의로 바뀔 수 있는 항목은 맨 아래 "논의 중"에 따로 모았다.

## 한 줄

출생 정보를 넣으면 차트와 "나를 설명해 주는 글"을 받고, 인생의 변곡점을 읽고, 다른 사람을 초대해 궁합을 보고, 결과를 공유한다. AI가 제시한 방향성을 투두로 실천해 조각을 모은다.

**대표 문구: 조각을 모은다**

앱 이름은 바꿀 예정이다. 브랜딩 전에 타깃과 기능을 먼저 정리한다. 기능 이름 "내 별명"도 새 이름에 맞춰 바뀐다.

## 한 문장 (포지셔닝)

**점성술 몰라도 읽히는 나, 나의 사람들, 나의 타이밍**

## 타깃

### 핵심 타깃 — 20대 초반~30대 초반 (여성 중심)
- 연애 · 궁합이 궁금하다
- 이직 · 이별 · 독립 같은 전환기에 "나 지금 어떤 시기야?"가 궁금하다
- 오래 쓰고 깊게 본다

### 확산 타깃 — 10대 후반 (만 14세 이상)
- 예쁜 결과를 인스타 스토리에 올린다. 그걸 본 친구들이 따라 들어온다
- 친구 궁합, 진로와 미래, 내 변곡점이 궁금하다

### 공통
- 점성술은 잘 모른다
- 결과를 스토리로 공유한다
- 그냥 믿기보다 "왜 그런지" 납득하고 싶어 한다

기능은 층별로 나누지 않는다. 두 층 모두 모든 기능을 쓴다. 말투나 표현이 부딪히면 핵심 타깃을 따른다. **가입은 만 14세 이상만 받는다** (만 14세 미만은 보호자 동의가 필요하다).

## 차별점 — 점성술 몰라도 읽힌다

- 해석 본문에 점성술 용어를 쓰지 않는다
- 문단마다 "왜 그런지" 근거를 표시한다
- 단정하지 않고 "이 시기의 주제"로 말한다
- 고정 문구 조합이 아니라 차트 전체를 엮은 개인화 해석이다

## 1.0.0 원칙

- **결제 없음, 횟수 제한 없음.** 리포트와 궁합을 몇 번이든 무료로 본다
- 한국어, 국내 출생지만
- 웹 · iOS · Android 동시 출시
- 해석은 점성술 용어 없이 쓰고, 문단 머리에 근거(차트 요소)를 작게 표시한다
- 건강 · 투자 · 미래 사건을 단정하지 않는다
- 수치와 시기(행성 · 하우스 · 각도 · 변곡점 연도)는 서버 코드가 계산하고, AI는 글만 쓴다

### 시기 (F4의 다섯 번째 영역) — 사람마다 다른 변곡점

변곡점은 두 종류를 합쳐 한 타임라인에 보여 준다.

**① 누구에게나 오는 마디** (연도는 내 차트로 계산)
| 마디 | 언제 |
|---|---|
| 토성 사각 | 만 21~22세 무렵 |
| 토성 귀환 | 만 29~30세 무렵 |
| 천왕성 대립 | 만 42세 무렵 |
| 두 번째 토성 귀환 | 만 58~59세 무렵 |

**② 나에게만 오는 구간** (트랜짓)
| 구간 | 계산 |
|---|---|
| 외행성 통과 | 토성 · 천왕성 · 해왕성 · 명왕성이 내 태양 · 달 · 상승궁과 합 · 사분 · 충을 이루는 기간 |

- 그래서 같은 나이라도 사람마다 변곡점의 시기와 개수가 다르다
- 구간은 날짜 하나가 아니라 기간으로 보여 준다 (예: 2027년 봄 ~ 2028년 초). 행성이 역행하면 한 구간 안에 여러 번 지나가는데, 하나의 구간으로 묶는다
- **지금 나의 구간**: 지금 어떤 구간에 있는지, 언제까지인지, 다음 변곡점은 언제인지를 맨 위에 보여 준다
- 출생 시각을 모르면 상승궁을 계산할 수 없으므로 상승궁 구간은 빼고 안내한다
- 연도와 기간은 서버 코드가 계산한다. AI는 계산된 구간을 받아 "이 시기의 주제"만 쓴다
- "이 시기의 주제"만 쓴다. 무슨 일이 일어난다고 쓰지 않는다
- 키론 귀환(만 50세 무렵)은 키론 계산 정확도를 검증한 뒤 정한다

## 논의 중 (오늘 대화에서 나온 변경 후보)

"정함"으로 표시한 것과 앞으로 정하는 것은 저장소 문서에 반영한다. 이름 · 로그인 · 궁합 점수 · 연령 제한은 결정이 바뀌므로 새 ADR이 먼저 필요하다.

| 항목 | 지금 문서 | 변경 후보 |
|---|---|---|
| 이름 | "별명" 확정 | **바꾸기로 함.** 새 이름은 브랜딩 단계에서 정함 |
| 타깃 | MBTI · 별자리를 즐기는 20~30대 | **정함.** 핵심 20대 초반~30대 초반 + 확산 10대 후반 (위 "타깃") |
| 연령 | 제한 없음 | **정함.** 만 14세 이상만 가입 |
| 로그인 | 구글 · 애플만, 해석부터 | **정함.** 스플래시 직후 가입 필수, 구글 · 애플 · 카카오 (아래 "정한 변경") |
| 궁합 점수 | 숫자 없이 키워드 3개 + 한 줄 | **정함.** 나 기준 0~100점 + 궁합 랭킹, 랭킹도 스토리 공유 (아래 "정한 변경") |
| 변곡점 | 정해진 마디 4개를 내 차트로 계산 | **정함.** 마디 4개 + 외행성 통과 구간, "지금 나의 구간"까지 1.0.0에 넣음 (위 "시기") |
| 공유 카드 | 요약 해석, 궁합 결과만 | **정함.** 궁합 점수 카드 · 랭킹 카드 · 다음 변곡점 카드 추가. 친구 3~5명 비교 카드는 랭킹 카드로 대신함 (아래 "정한 변경") |
| 무료 범위 | 리포트 1편 · 궁합 하루 5번 제한 | **정함.** 1.0.0은 횟수 제한 없음 (아래 "정한 변경") |
| 브랜딩 | "도장과 책력", Pretendard | 밤하늘 네이비 · 라벤더 초안 (방향 미정) |

### 정한 변경: 스플래시 직후 가입

- 흐름: 스플래시 → 구글 · 애플 · 카카오 로그인 → 만 14세 이상 확인 → 출생 정보 입력 → 차트 → 요약 해석
- 입력 · 차트(F1 · F2)도 로그인한 뒤에 쓴다. 로그인 없이 쓰는 화면은 공유 페이지 하나뿐이다
- 공유 링크로 온 사람은 글을 로그인 없이 보고, "나도 보러 가기"를 누르면 가입부터 한다
- 출생 정보는 처음부터 계정에 저장된다. 기기에만 저장하던 흐름(F1)은 필요 없다
- 이유: 만 14세 확인을 가입 때 한 번에 하고, 궁합 랭킹 · 조각처럼 계정이 필요한 기능이 늘었다
- 카카오 로그인을 더한다. 10대 확산 타깃은 구글 · 애플 계정보다 카카오 계정이 익숙하다. iOS에서 카카오 · 구글 로그인을 넣으면 애플 로그인도 있어야 하는데(앱스토어 심사 규정) 이미 있다
- 카카오에서 연령대를 받아 만 14세 확인에 쓸 수 있는지 확인한다 (연령대 동의 항목은 카카오 쪽 검수가 필요할 수 있다)
- 이탈을 줄이려면 스플래시와 로그인 사이에 소개 화면 2~3장을 두는 것을 검토한다
- 저장소 결정과 다르므로 새 ADR이 필요하다 (결정 005 "구글 · 애플만, 해석을 받을 때 로그인 요구", 결정 006 "차트 계산은 로그인 없이"를 대체). 서버의 로그인 없는 차트 계산 API(`POST /charts`)도 바뀐다

### 정한 변경: 나 기준 궁합 점수와 랭킹

**나 기준 점수**
- 궁합 결과에 0~100점을 보여 준다. 키워드 3개 + 한 줄은 그대로 둔다
- "이 사람이 나에게 어떤 사람인지"를 기준으로 계산한다. 상대의 행성이 **내 개인 행성(태양 · 달 · 수성 · 금성 · 화성)**에 만드는 각도에 가중치를 둔다. 그래서 내가 본 상대의 점수와 상대가 본 나의 점수가 다를 수 있다
- 관계 유형(연애 / 친구 / 일)마다 가중치가 달라 점수도 다르다
- 점수는 서버 코드가 계산하고, AI는 점수와 각도를 받아 글만 쓴다 (1.0.0 원칙 그대로)

**궁합 랭킹**
- 내가 궁합을 본 사람들을 점수순으로 보여 준다. 관계 유형별로 따로 본다 (예: 연애 랭킹, 친구 랭킹)
- 랭킹에 저장하는 것은 상대의 부를 이름 · 점수 · 키워드뿐이다. 직접 입력한 상대의 출생 정보는 지금처럼 서버에 저장하지 않는다
- 상대 이름은 내가 붙인 이름이다

**스토리 공유**
- 궁합 점수 카드: 두 사람의 부를 이름 + 점수 + 한 줄 ("나랑 너, 몇 점?")
- 랭킹 카드: "내 친구 궁합 TOP 3"처럼 상위 몇 명을 카드로 올린다
- 출생 정보와 근거는 카드에 나오지 않는다 (F6 규칙 그대로)

**정해야 할 것**
- 점수 계산 규칙 (각도 종류별 점수, 행성 조합별 가중치, 0~100 변환)
- 낮은 점수를 보여 주는 방식 (숫자만 둘지, "다른 결의 사이" 같은 문구를 붙일지)
- 랭킹 카드에 다른 사람 이름을 그대로 보여 줄지, 이니셜이나 별칭으로 가릴지
- 랭킹 카드에 몇 명까지 넣을지 (TOP 3 / TOP 5)
- 저장소 결정과 다르므로 새 ADR이 필요하다 (release-1.0.0 F5 "점수는 보여 주지 않는다", F6 공유 범위를 대체)

### 정한 변경: 사람마다 다른 변곡점

- 1.0.0의 시기 영역에 정해진 마디 4개와 함께 외행성 통과 구간(트랜짓)을 넣는다. 자세한 내용은 위 "시기"
- 이유: 마디 4개만으로는 나이가 같으면 시기도 거의 같아 보인다. 10대 확산 타깃은 토성 귀환이 멀어서 궁금증이 약하다. 외행성 통과는 사람마다 달라서 "어떻게 알았지?"가 커진다
- 저장소 product.md는 트랜짓을 1.2.0으로 미뤄 두었다. 외행성 통과 구간만 1.0.0으로 당기고, 오늘의 운세처럼 매일 바뀌는 트랜짓은 그대로 1.2.0 이후다
- 출시 기준에 추가: 외행성 통과 구간의 시작 · 끝 시기가 기준 천체력(NASA JPL 등)으로 계산한 값과 같은 달이다

**정해야 할 것**
- 타임라인을 몇 살까지 보여 줄지
- 어떤 각도까지 변곡점으로 볼지 (합 · 사분 · 충만 / 삼분 · 육분도 포함)
- 구간의 시작과 끝을 정하는 허용 오차 각도
- 변화의 크기(큰 변화 / 작은 변화)를 나누는 규칙 (예: 천왕성 · 명왕성 > 해왕성 > 토성, 태양 · 달 > 상승궁)

### 정한 변경: 공유 카드

1.0.0에서 스토리로 올릴 수 있는 카드는 네 가지다.

| 카드 | 들어가는 것 |
|---|---|
| 요약 해석 카드 | 한 줄 총평 + 키워드 |
| 궁합 점수 카드 | 두 사람의 부를 이름 + 나 기준 점수 + 한 줄 ("나랑 너, 몇 점?") |
| 랭킹 카드 | "내 친구 궁합 TOP 3"처럼 상위 몇 명의 이름 + 점수 |
| 다음 변곡점 카드 | "내 다음 변곡점은 2027년 봄" + 그 시기의 주제 한 줄 |

- 모든 카드에 출생 정보(날짜 · 시각 · 장소)와 근거(차트 요소)는 나오지 않는다
- 카드를 누르면 공유 페이지가 열리고 "나도 보러 가기"를 누르면 가입부터 한다
- 다음 변곡점 카드는 리포트의 일부지만 시기와 주제 한 줄만 넣는다. 리포트 본문은 지금처럼 공유하지 않는다
- 친구 3~5명 비교 카드는 따로 만들지 않는다. 랭킹 카드가 같은 역할을 한다
- 저장소 F6(공유 범위: 요약 해석 · 궁합 결과만, 리포트는 공유 안 함)을 바꾸므로 궁합 점수 ADR과 함께 정리한다

### 정한 변경: 1.0.0은 횟수 제한 없음

- 심층 리포트, 궁합 리포트, 궁합 결과를 횟수 제한 없이 무료로 본다
- 같은 차트(같은 두 사람)의 글은 한 번만 만들고 다시 열면 같은 글이 나온다. 그래서 같은 사람을 반복해서 봐도 AI 비용은 한 번만 든다
- 비정상적인 반복 요청(자동화 · 남용)은 막는다. 이것은 기능의 횟수 제한이 아니라 서버 보호용 요청 속도 제한이다 (서버에는 이미 주소별 요청 수 제한이 있다)
- 이유: 랭킹과 조각을 쌓으려면 궁합을 많이 봐야 하고, 확산 타깃이 제한 없이 친구들을 넣어 보게 한다
- 고려할 점
  - AI 비용이 사용량만큼 나간다. 출시 후 하루 생성 건수와 비용을 본다
  - 저장소 product.md는 "유료 리포트를 1.0.0에서 무료로 풀지 않는다(나중에 유료로 돌리기 어렵다)"고 정해 두었다. 1.1.0에서 무엇을 유료로 할지(추가 리포트 / 방향성 제시 VIP / 광고 제거)를 이 결정에 맞춰 다시 본다
- 저장소 release-1.0.0의 사용자 결정("무료지만 횟수를 제한한다")과 출시 기준("리포트 무료 1편, 궁합 하루 5번이 서버에서 지켜진다")을 바꾼다
