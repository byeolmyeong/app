# 032. 앱 이름은 "별명" 그대로 간다

> 상태: 활성 · 결정일 2026-11-18 · 결정 013("별명"을 바꾼다)을 대체한다. 출처: docs/raw/2026-11-18-figma-brand.md

## 맥락
- 결정 013 은 "별명" 이 받침이 연달아 와 한 번에 안 읽히고 먼저 '닉네임'으로 읽힌다는 이유로 이름을 바꾸고, 새 이름은 브랜딩 단계에서 정하기로 했다.
- 브랜딩 단계에서 소유자가 브랜드 시안(Figma)과 함께 "우리 앱 별명 그대로 하기로 정했어" 라고 정했다(2026-11-18).

## 결정
- 앱 이름은 **별명**이다. 문서의 "가칭" 표시를 지운다.
- 이름 풀이: **별(★)이 지어 준 이름(名)**. 사전 뜻 별명(別名, 나를 부르는 또 하나의 이름)과 겹친 말이다. 앱 문구 "별이 붙여 준 나의 별명"(`strings.home.title`)이 이 뜻이다(소유자 확인 2026-11-18).
- 기능 이름 "내 별명"(요약 풀이)도 그대로다.
- 저장소 이름(`byeolmyeong-app`·`byeolmyeong-api`)은 이름과 맞으므로 그대로다.

## 근거
- 013 의 걱정(먼저 '닉네임'으로 읽힘)은 이름 풀이를 알면 오히려 기억에 남는 점이 된다. 별이 지어 준 또 하나의 이름 = 출생 차트로 읽은 나라는 제품과 맞는다.
- 받침이 연달아 오는 읽기 어려움은 브랜드 그림(네 갈래 별, 결정 033)과 스토어 부제로 보완한다.

## 대안
- 013 대로 새 이름 짓기 — 소유자가 고르지 않았다.

## 결과·재검토 조건
- [확인 필요] 상표(9류 앱 · 45류 점성/운세) · 스토어 동명 앱 · 도메인. 013 에서 넘어온 확인 거리다. 막히면 이 결정을 다시 본다.
- 스토어 부제(이름 옆 한 줄)는 출시 준비 때 정한다.
