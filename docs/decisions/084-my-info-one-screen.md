# 084. 마이 카드의 버튼 둘("프로필 수정" · "출생 정보 수정")을 "내 정보" 하나로 합친다 — 카드 전체가 내 정보로 가고, 출생 정보는 내 정보 안에 둔다

> 상태: 활성 · 결정일 2026-11-26(소유자 "엉 합치자") · 결정 056 의 1 중 별명 카드 아래 버튼 둘(앱에서는 "프로필 수정" · "출생 정보 수정", 소유자 2026-11-21)과 056 의 3 중 계정 화면의 이름 · 순서를 대체한다 · 056 의 6(출생 정보 수정 화면 · 확인 창)은 그대로다 · 시안(피그마 보드 16 · 16-1)은 고치지 않는다 · 2 의 출생 정보 줄 "지금 값 한 줄 + 수정 ›" 과 닉네임 줄의 값은 087 이 대체(이름과 꺾쇠만)

## 맥락
- 마이 첫 화면 별명 카드 아래에 버튼 둘이 나란히 있었다. "프로필 수정" 은 계정 화면(`/my/account` — 프로필 그림 · 닉네임 · 연결된 계정 · 로그아웃 · 계정 삭제)으로, "출생 정보 수정" 은 출생 정보 수정 화면(`/my/birth`)으로 갔다.
- 둘 다 "내 것을 보고 고친다" 는 같은 일이다. 소유자는 이 둘을 한 곳("내 정보")으로 합치기로 했다.

## 결정
1. **마이 별명 카드는 카드 전체를 누르면 내 정보(`/my/account`)로 간다.** 카드 아래 버튼 둘은 뺀다. 카드의 다른 칸(프로필 그림 · 닉네임 · "해 별자리 · 별명을 받은 지 N일" · 한 줄 별명 · 출생 정보 한 줄 · 해 별자리 그림)은 그대로다.
   - 카드 오른쪽, 프로필 그림 · 닉네임 줄의 끝에 꺾쇠 › 를 둔다. 홈 카드들의 꺾쇠(`ChevronRight` — 같은 모양, 22, hint 색)와 같다.
   - 화면 읽기 이름은 보이는 글 차례대로 + "내 정보"(결정 078 의 1 과 같은 방식 — 보이는 글자가 없으면 어디로 가는지 이름에 남긴다).
2. **계정 화면의 제목을 "내 정보" 로 바꾸고 이 순서로 둔다.** 주소(`/my/account`)는 그대로다.
   1. 프로필 — 위 가운데 프로필 그림(누르면 고르기 시트) · 닉네임 줄
   2. **출생 정보** — 이름 "출생 정보", 그 아래 지금 값 한 줄(별명 카드의 출생 정보 한 줄과 같은 형식, 예 "1999년 3월 8일 · 오후 2:10 · 서울 강남구" · 시각을 모르면 "1999년 3월 8일 · 시각 모름"), 오른쪽에 "수정 ›". 누르면 출생 정보 수정(`/my/birth`)으로 간다. 기기에 출생 정보가 없으면 값 줄 없이 이름과 "수정 ›" 만 — 들어가는 길은 늘 있다(전에 버튼이 늘 있던 것과 같다).
   3. 연결된 계정
   4. 로그아웃(따로 한 카드, 가운데 창으로 묻는다)
   5. 계정 삭제(맨 아래 작은 밑줄 글자)
   - 닉네임 · 출생 정보 · 연결된 계정은 지금처럼 한 카드 안의 줄이다(056 의 3 의 "한 카드" 그대로, 줄 사이에 옅은 선). 화면이 스크롤되지 않으니 작은 기기에서도 넘치지 않게 카드를 늘리지 않는다.
3. **출생 정보 수정 화면과 "수정하기" 확인 창은 그대로 둔다.** 차트를 다시 짓는 무거운 동작이라 한 단계 안쪽 · 한 번 더 묻기를 안전장치로 남긴다.
   - 그 화면을 주소로 바로 열어 돌아갈 곳이 없을 때 뒤로 가기는 마이(`/my`) 대신 내 정보(`/my/account`)로 간다 — 이제 들어오는 곳이 내 정보다(닉네임 · 계정 삭제 화면과 같다).

## 근거
- 같은 일(내 것 보고 고치기)을 하는 입구가 둘이면 어느 쪽을 눌러야 할지 고른다. 카드 하나가 "나" 를 보여 주고 누르면 "내 정보" 로 가면 고를 것이 없다.
- 출생 정보는 바꾸면 별명 · 풀이가 모두 새로 만들어진다. 첫 화면에서 한 번 더 들어간 곳(내 정보 → 수정 → 확인 창)에 두어 잘못 누를 일을 줄인다.

## 대안
- 버튼 둘 그대로(056) — 소유자가 합치기로 했다.
- 내 정보 화면에서 출생 정보를 바로 고치는 칸으로 — 차트를 다시 짓는 동작이라 따로 화면 · 확인 창을 남긴다.
- 출생 정보 · 연결된 계정을 따로 카드로 — 화면이 스크롤되지 않아 작은 기기에서 넘칠 수 있다. 한 카드 안의 줄로 둔다.

## 결과·재검토 조건
- 결정 056 앞머리에 대체 표시를 단다.
- 시안(피그마 보드 16 의 카드 버튼 둘 · 16-1 의 제목 "계정")은 고치지 않는다. 보드와 앱이 이 두 곳에서 다르다.
- 내 정보에 줄이 더 늘어 작은 기기에서 넘치면 화면을 스크롤되게 바꾼다.
