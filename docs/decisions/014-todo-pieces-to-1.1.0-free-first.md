# 014. 투두·조각·레벨업은 1.1.0 으로 옮기고, 방향성 제시는 무료로 시작해 나중에 유료화하며, 심층·궁합 리포트는 계속 무료로 둔다

> 상태: 활성 · 결정일 2026-11-11 · 출처: docs/raw/2026-11-11-session-planning-1.0.0.md · docs/decisions/008-ads-and-ad-removal.md 의 "방향성 제시 VIP 는 1.0.0 무료판보다 깊은 글"을 보완한다

## 맥락
F11(투두·조각·레벨업)은 투두 하나당 조각 수, 레벨 기준, 레벨이 오르면 달라지는 것, 투두가 새로 생기는 주기, 화면 경로가 모두 [확인 필요]였다. F10(방향성 제시)은 1.0.0 에 "짧은 무료판"을 주고 1.1.0 에 더 깊은 VIP 를 팔기로 되어 있었다. 결정 011 로 리포트도 1.0.0 에서 제한 없이 무료가 되어, 1.1.0 에 무엇을 유료로 할지가 비어 있었다.

## 결정
- F11 투두·조각·레벨업을 1.0.0 에서 빼고 1.1.0 으로 옮긴다. 1.0.0 의 대표 문구 "조각을 모은다"도 함께 옮긴다.
- F10 방향성 제시는 1.0.0 에 남긴다. 짧은 판이 아니라 기능 전체를 무료로 준다.
- 방향성 제시는 1.0.0 에 무료로 주고, 추후 같은 기능을 유료로 바꾼다. 무료판과 유료판을 따로 만들지 않는다.
- 심층 리포트(성격·관계·일·감정·시기)와 궁합 리포트는 유료로 바꾸지 않고 계속 무료로 둔다.

## 근거
- F11 은 정할 것이 많아 1.0.0 일정 안에 규칙·화면을 확정하기 어렵다. 방향성 제시가 먼저 쓰여야 투두로 뽑을 실천 항목의 모양도 정해진다.
- 1.0.0 의 재방문 이유는 궁합 랭킹(결정 010)과 "지금 나의 구간"(결정 012)이 맡는다.
- 무료판과 유료판을 따로 만들면 글 생성 규칙이 두 벌이 된다.
- 리포트는 "점성술 몰라도 읽힌다"를 가장 잘 보여 주는 기능이라 막지 않는다. 심층 리포트에는 변곡점 타임라인(시기)이, 궁합 리포트에는 랭킹·공유로 이어지는 관계 해석이 있어 확산을 맡는다.

## 대안
- F11 을 1.0.0 에 두고 규칙을 서둘러 정하기 — 보상·레벨 규칙은 나중에 바꾸기 어렵다.
- 방향성 제시 짧은 무료판 + 깊은 VIP(결정 008 원안) — 사용자가 기능 전체를 무료로 주기로 했다.

## 결과·재검토 조건
- 1.0.0 대표 문구를 새로 정해야 한다. [확인 필요]
- 유료로 바꾸는 것은 방향성 제시뿐이다. 1.0.0 에서 무료로 보던 사용자의 반발이 생길 수 있으므로, 유료로 바꿀 때 이미 만든 방향성 제시 글은 계속 볼 수 있게 할지 정한다. [확인 필요]
- 1.1.0 의 수익원은 방향성 제시 유료화와 광고·990원 광고 제거다(결정 008). 리포트 판매는 하지 않으므로 결정 002 의 "리포트 건당 판매"를 다시 본다. [확인 필요]
- [확인 필요] 유료로 바꾸는 시점(1.1.0 인지 그 뒤인지)과 가격. 결정 002·008 과 함께 본다.
- F11 의 [확인 필요](조각 수, 레벨 기준, 레벨 보상, 투두 주기, 화면 경로)는 1.1.0 계획에서 정한다.
