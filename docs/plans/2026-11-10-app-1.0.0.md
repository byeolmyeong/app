# 앱 1.0.0

> 상태: 승인(태스크 1~3 먼저 실행) · 기준 2026-11-10 · 이전 계획(2026-11-10-mvp.md, 지움)을 대체한다(그 계획의 태스크 1 은 완료됐다). 서버 쪽 계획: `../byeolmyeong-api/docs/plans/2026-11-10-api-mvp.md`

## 목표
- 무엇을: docs/release-1.0.0.md 의 기능 F1~F10 을 웹·iOS·Android 에서 쓸 수 있는 앱.
- 누구를 위해: 점성술은 모르는 20대 초반~30대 초반(핵심)과 10대 후반(확산, 만 14세 이상). docs/product.md
- 끝나면: 스플래시 → 로그인(구글·애플·카카오, 만 14세 확인) → 출생 정보 → 요약 해석 → 심층 리포트(변곡점) → 궁합 점수·랭킹 → 공유 카드 → 방향성 제시 → 계정 삭제가 한 벌의 코드로 세 플랫폼에서 된다.

## 내 결정 (묻지 않고 고른 기본값)
- 서버가 준비되기 전에도 화면을 만들 수 있게, API 응답 예시(JSON)를 `src/lib/fixtures/` 에 두고 테스트와 개발용 가짜 서버가 함께 쓴다.
- 화면 문구는 `src/content/strings.ts` 한 파일에 모은다. 이유: 1.2.0 에서 영어를 붙인다. 앱 이름이 정해지면 이 파일에서 한 번에 바꾼다(결정 013).
- 받은 차트와 글은 기기에 보관해 다시 열 때 요청하지 않는다.
- 어두운 화면 모드는 만들지 않는다.

## 승인 메모 (2026-11-10, 사용자)
- 태스크 1~3 을 먼저 실행한다. 4번부터는 외부 준비(로그인 클라이언트 등록 등)가 필요하다.
- 화면 디자인은 프로덕트 디자이너가 전부 다시 작업한다. 그래서 지금은 시안(docs/design/screens-1.0.0.html)을 기능이 보이는 수준으로만 옮기고 다듬지 않는다. 색·글자·간격을 `src/constants/theme.ts` 한 곳에, 부품을 `src/components/` 에 모아 나중에 통째로 바꿀 수 있게 한다.
- 디자이너에게 주는 설명: docs/design/product-brief-1.0.0.md (보드 product-brief-1.0.0.png)

## 전역 제약
- 패키지 설치는 `npx expo install <패키지>` 만. Expo·EAS·React Native API 는 쓰기 전에 공식 문서를 확인한다(AGENTS.md). Node 22.
- 색·글자·간격은 `src/constants/theme.ts` 의 값만 쓴다. 화면에 색 값을 직접 적지 않는다.
- 화면 문구를 컴포넌트에 직접 적지 않는다. `strings.ts` 에서 가져온다.
- 세션 토큰·출생 정보를 로그와 분석 이벤트에 남기지 않는다.
- 새 동작은 실패하는 테스트를 먼저 본다. 화면은 웹에서 열어 콘솔 에러 0 과 폭 390px 레이아웃을 스크린샷으로 남긴다.

  - 지금: 오늘에 걸친 변곡점 · 구간(제목 · 본문 · 언제까지), 없으면 없다는 말과 다음 구간. 바로 아래에 방향성(미래) — `ReportView` 의 자리 이름을 `timingEnd` → `timingAfterNow` 로 바꿨다. 시기 탭이 보일 때만 받는 것, 실패가 그 칸 안에만 보이는 것, 기다리는 동안 강제 업데이트를 미루는 것은 그대로다.
  - 올해 · 내년: 오늘부터 내년 끝까지에 걸친 변곡점 · 구간 전부. "지금 지나는 중" · "2026년 남은 기간에 시작" · "2027년에 시작". 걸친 변곡점은 초록 테두리 줄로 묶음 맨 위. 없는 해에는 없다고 적는다.
  - 앞으로: 다음 변곡점 카드 → 공유 버튼 → 누구에게나 비슷한 나이에 온다는 설명 → 더 뒤의 변곡점(작은 줄) → 내년 뒤에 시작하는 구간(큰 변화 먼저, 10년 안 먼저, "이후 구간 더 보기" 30개씩).
  - 지나온 시기: "지나온 시기 보기" 를 누르기 전에는 줄을 그리지 않는다. 열면 지난 변곡점(흐린 글씨)과 지난 구간을 새것부터.
- 날짜: `timing.ts` 에 `splitByNow`(지난 것 · 지금 · 올해 시작 · 내년 시작 · 내년 뒤, 글자 비교)와 `nextYearLabel`(오늘의 해 글자 다음 해의 이름표, 한 곳)을 더했다. 오늘은 `current.date` 다. 시기를 그리는 두 파일에 `Date` 가 없다는 것을 테스트가 본다.
