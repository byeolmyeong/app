# 072. 웹이 시작할 때 인터넷은 되는데 서버만 닿지 않으면 "불러오지 못했어요"(19)를 보이고, 끊김 띠 · 20-1 은 정말 끊겼을 때만

> 상태: 활성 · 결정일 2026-11-21(소유자 — "인터넷은 되는데 서버만 안 될 때는 20-1 대신 19", 세션 67 경유) · 결정 068 의 4 중 "홈 + 연결 끊김 띠(20) / 20-1" 부분을 대체한다(로그인으로 보내지 않는 것 · 30초마다 다시 확인 · 401 이면 로그인은 그대로)

## 맥락
- 결정 068 의 4 는 웹이 시작할 때 서버에 닿지 못하면(401 이 아니면) 받아 둔 홈 + 끊김 띠(20), 없으면 20-1 "인터넷에 연결되어 있지 않아요" 를 보였다. 인터넷은 되는데 서버만 내려간 경우에도 "인터넷" 을 탓하게 된다.

## 결정
1. 세션을 확인하지 못했을 때(offline) 인터넷 연결 상태로 나눈다. 정말 끊겼으면 지금처럼 20-1(받아 둔 홈이 있으면 홈 + 끊김 띠 20).
2. 인터넷은 되는데 서버만 닿지 않으면 끊김 대신 19 "불러오지 못했어요" — 홈은 "홈을 불러오지 못했어요", 가입 단계는 "불러오지 못했어요". "다시 보기" 는 세션을 다시 확인한다.
3. 받아 둔 홈이 있으면 그대로 보이고 끊김 띠는 두지 않는다(띠의 글이 사실과 다르지 않게).

## 결과·재검토 조건
- 받아 둔 홈 + 서버만 내려간 동안은 서버를 부르는 칸(오늘의 하늘 등)이 비어 보일 수 있다 — 30초마다 다시 확인해 돌아오면 채운다.
