# 웹 백엔드 공통 규칙

- 세션·캐시에서 꺼낸 객체는 직렬화된 복사본이다. 모델 메서드를 부르기 전에 다시 조회한다.
- 사용자 입력을 HTML·이메일 템플릿에 넣을 때 이스케이프한다. `String.replace`의 대체 문자열 자리에 값을 그대로 넘기지 않는다(`$&` 등 특수 시퀀스).
- 고유 번호 발급은 기존 행 스캔 `+1`이 아니라 시퀀스 테이블의 원자적 증가로 한다.
- 마이그레이션은 건너뛰지 않는다. 컬럼 추가와 backfill은 같은 병합 단위에 둔다.
- 장시간 배치를 트리거하는 API는 202 즉시 응답 + 백그라운드 실행 + 중복 실행 가드로 만든다.
