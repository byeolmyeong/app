# 015. 1.0.0 부터 결과를 보기 전에 15초 광고를 보여 준다

> 상태: 활성 · 결정일 2026-11-11 · 출처: docs/raw/2026-11-11-session-planning-1.0.0.md · docs/decisions/008-ads-and-ad-removal.md 의 "1.1.0 부터 결과를 보기 전에 광고"에서 시작 시점을 1.0.0 으로 당기고 길이를 15초로 정한다(008 의 나머지는 그대로)

## 맥락
결정 011·014 로 1.0.0 의 리포트·궁합은 횟수 제한 없이 무료가 되었고, 심층·궁합 리포트는 앞으로도 무료다. 유료로 바꾸는 것은 방향성 제시뿐이라, 무료 사용자의 AI 비용을 메울 수익원이 필요하다.

## 결정
- 1.0.0 부터 결과를 보기 전에 15초 광고를 보여 준다. 광고를 끝까지 보면 결과가 열린다.
- 대상 결과: 요약 해석, 심층 리포트, 궁합 결과, 궁합 리포트, 방향성 제시.
- 같은 결과를 다시 열 때는 광고를 다시 보여 주지 않는다. [확인 필요]
- 결제는 1.0.0 에 여전히 없다. 광고는 결제가 아니다.

## 근거
- 무료로 주는 기능이 늘어난 만큼 광고가 AI 비용을 메운다.
- 15초는 결과를 기다리는 시간(리포트 생성 중)과 겹쳐 체감이 덜하다.

## 대안
- 1.1.0 부터 광고(결정 008 원안) — 1.0.0 의 비용을 메울 수단이 없다.
- 첫 요약 해석만 광고 없이 — 첫인상 이탈을 줄이지만 사용자가 모든 결과 앞에 두기로 했다. 이탈이 크면 다시 본다.

## 결과·재검토 조건
- 광고 SDK 가 1.0.0 에 들어간다. 개인정보 처리방침과 스토어 데이터 수집 신고를 고치고, iOS 는 추적 허용 요청(ATT)이 필요할 수 있다.
- 확산 타깃에 만 14~18세가 있다. 미성년자에게는 맞춤형 광고를 끄는 설정이 필요할 수 있다. [확인 필요] 광고 SDK 의 연령 설정.
- 990원 광고 제거 상품을 1.0.0 에 같이 넣을지는 정하지 않았다(결정 008 은 1.1.0). 1.0.0 에 넣지 않으면 광고를 끌 방법이 없다. [확인 필요]
- 웹에서도 광고를 보여 줄지, 광고를 불러오지 못하면 결과를 그냥 열지. [확인 필요]
- 광고 시청 여부는 서버가 판정한다(앱의 값으로 결과를 열지 않는다, docs/golden-rules.md 프로젝트 규칙). [확인 필요] 광고 SDK 의 서버 검증 방식.
- 성공 지표에 "광고 시청 완료율"과 "광고 앞 이탈률"을 본다. 첫 요약 앞 이탈이 크면 첫 요약을 예외로 두는 것을 다시 본다.
