# 012. 1.0.0 의 변곡점에 외행성 통과 구간과 "지금 나의 구간"을 넣는다

> 상태: 활성 · 결정일 2026-11-11 · 출처: docs/raw/2026-11-11-session-planning-1.0.0.md · docs/release-1.0.0.md F4 "시기"를 넓히고, docs/product.md 의 "1.2.0 이후 트랜싯" 중 외행성 통과만 1.0.0 으로 당긴다

## 맥락
1.0.0 명세의 시기 영역은 정해진 마디 네 개(토성 사각, 토성 귀환, 천왕성 대립, 두 번째 토성 귀환)의 연도를 내 차트로 계산했다. 마디 네 개는 나이가 같으면 시기도 거의 같다. 확산 타깃인 10대 후반은 토성 귀환까지 멀어 궁금증이 약하다. 소유자는 "계산해서 사람마다 다른 변곡점 구간이 나타나게" 하기로 정했다.

## 결정
- 시기 타임라인에 두 종류를 함께 보여 준다.
  - 누구에게나 오는 마디 네 개(기존).
  - 나에게만 오는 구간: 토성·천왕성·해왕성·명왕성이 내 태양·달·상승점과 합·사분·충을 이루는 기간.
- 구간은 날짜 하나가 아니라 기간(시작~끝)으로 보여 준다. 역행으로 여러 번 지나가면 한 구간으로 묶는다.
- 맨 위에 "지금 나의 구간"(지금 어떤 구간인지, 언제까지인지, 다음 변곡점은 언제인지)을 보여 준다.
- 기회 구간을 더한다(2026-11-11 추가): 목성이 내 태양·달·상승점·중천·금성과 합·삼분을 이루는 기간, 목성이 5·7·11하우스를 지나는 기간. 사용자가 변곡점에서 가장 궁금해하는 "그때 나에게 무엇이 오는가"(귀인·인연)에 답한다. 단정하지 않고 "~하기 쉬운 시기"로 쓴다.
- 구간마다 영역(사람·인연 / 일 / 돈 / 나 자신)을 붙인다. 자극받는 하우스로 정한다.
- 출생 시각을 알면 운명적 만남 구간을 더한다(2026-11-11 추가): 목성·토성·외행성이 내 버텍스와 합을 이루는 기간. 버텍스는 1.0.0 에 넣고 키론은 넣지 않는다.
- 출생 시각을 모르면 상승점 구간은 빼고 안내한다.
- 기간은 서버 코드가 계산한다. AI 는 "이 시기의 주제"만 쓴다(기존 규칙 그대로).
- 오늘의 운세처럼 매일·매주 바뀌는 트랜짓은 그대로 1.2.0 이후다.

## 근거
- 외행성 통과는 사람마다 시기와 개수가 달라 "나만의 변곡점"이 된다.
- 행성 위치 계산은 서버에 이미 있다(결정 006). 미래 시각의 위치를 같은 방법으로 구하면 된다.

## 대안
- 마디 네 개로 출시하고 1.2.0 에 확장 — 일정은 안전하지만 사용자가 1.0.0 에 넣기로 했다.

- 다음 변곡점 카드(결정 010)의 근거가 된다.
