# 1.1.0 기능 명세

## 한 줄
자세한 풀이(나 탭 + 시기)를 상품 하나로 팔고, 궁합(연애 · 친구, 모두 무료)과 내 궁합 링크로 새 사람이 들어오는 길을 연다. 홈은 메뉴판으로 단순해지고, 음악과 공지사항이 생긴다. 광고는 없다.

## 사용자 결정
- 범위: 결제 · 궁합(내 궁합 링크까지) · 음악 · 공지사항. 광고 · 990원 광고 제거 없음. 방향성 제시는 따로 두지 않고(작은 실천이 맡음), 친구창 · 투두 · 그룹 궁합은 1.2.0 이후. 결정 100
- 자르는 선: 결제 → 궁합 핵심(직접 입력 · 별 지도 · 결과 · 공유 카드) → 음악 · 공지사항 → 링크 묶음(내 궁합 링크 · 앱 연결 · 앱 받기 페이지 · 공유하기). 밀리면 링크 묶음만 1.1.x. 결정 100 의 7
- 결제: "자세한 풀이" 상품 하나(나 탭 + 시기, 비소모성), 정가 4,990원 · 출시 한 달 2,990원, 스토어 인앱결제만(RevenueCat), 웹 결제 없음. 1.0.0 에서 하나라도 받은 계정은 둘 다 열림. 결정 101
- 궁합: 사이 둘(연애 · 친구), 나 기준 점수, 모두 무료(보이는 한도 없음 · 높은 안전 한도만), 상대 출생 정보 저장(궁합에만, 지우면 함께). 결정 104
- 홈: 오늘의 하늘 한 줄 + 메뉴판(나 · 나의 시기 · 나의 사람들). 아래 탭 다섯(홈 · 나 · 시기 · 궁합 · 마이). 결정 102
- 웹: 웹 앱은 남는다(없앨지는 따로). 결제는 앱에서만. 내 궁합 링크를 안드로이드 · 컴퓨터로 열면 안드로이드 앱이 나오기 전까지 웹에서 이어서 본다. 결정 100 의 5 · 104 의 7
- 안드로이드: 1.1.0 때 나오지 않을 수 있다 — 링크 앱 받기 페이지는 Google Play 를 앱이 나온 뒤에만 보인다. 결정 104 의 7

## 기능

### P1. 결제 — 자세한 풀이 (결정 101)
- 나 탭 · 시기 탭의 "자세한 풀이 받기"에서 산다(어느 쪽이든 같은 상품). 결제 시트에 가격(스토어가 주는 글자) · 구매 복원.
- 받을 수 있는지는 서버가 판정한다(RevenueCat 확인, 없으면 402 `PURCHASE_REQUIRED` → 결제 시트). 앱이 "샀는지"를 스스로 판정하지 않는다.
- 1.0.0 에서 받은 계정은 둘 다 열림. 출생 정보를 고친 뒤 다시 받기는 무료.
- 구매 복원: 결제 시트와 마이.
- 웹: "앱에서 받기" 안내만(산 계정이면 풀이는 보인다).

### P2. 궁합 (결정 104)
- 궁합 탭: 별 지도(나 가운데, 가까울수록 잘 맞음, 테두리 색 = 사이) + 전체 순위(맨 위 새로 온 별 줄 · 보는 중 줄, ? 말풍선 "내 기준 점수예요"). 머리 오른쪽 + → 새 궁합 시트(직접 입력 · 내 궁합 링크). 0명이면 빈 하늘 + 두 버튼.
- 입력: 화면 하나(제목 "궁합"), 사이 칩(홈 연애/친구로 오면 켜짐, 탭에서 오면 둘 다 꺼짐), 이름 · 생일 · 시각 · 장소.
- 보는 중: 버튼 없이 기다림(로딩 음악). 다 되면 결과로. 나가면 "궁합이 나왔어요" 알림.
- 결과: 요약 카드(가운데 "나 ─ 점수 ─ 상대", 배지, 이유 펼침 — 별 이름 · 각도)와 자세한 풀이(끌림 · 대화 · 갈등 · 오래가기 + 작은 실천)를 한 번에. 60점 아래도 같은 모양(낮은 점수 표시 없음). 머리에 공유 · ⋯(이 궁합 지우기).
- 내 궁합 링크: 계정마다 하나, ⋯ 에서 다시 만들기(옛 링크 닫힘), 주 버튼 "공유하기"(휴대폰 기본 공유 창) · 링크 칸 옆 복사. 받은 쪽은 링크 미리보기(랜딩 OG).
- 링크 받은 사람: 앱 있음 · 가입함 / 가입 전 / 앱 없음(아이폰 App Store · 안드로이드 · 컴퓨터는 웹에서 이어서) / 닫힌 링크 / 내 링크 · 이미 본 사람.
- 보낸 사람: 새로 온 별은 순위 맨 위 줄("사이 고르기") → 사이를 고르면 내 쪽 점수 · 글이 만들어짐. 여럿이면 줄이 쌓임.
- 지우기: 결과 ⋯ 로 한 명, 탭 "편집" → 체크 → "N명 지우기". 링크로 온 사람은 내 쪽만 지워짐.
- 공유: 결과 카드(C 구성) · 내 하늘 카드(모두, 초성으로 바꾸기 처음 켜짐, 사이 색 없음). 스토리는 링크 자동 복사 + 알림 "링크 스티커에 붙여 넣으면…". 스토리에 음악은 넣지 않는다(결정 105).
- 알림: "○○ 님이 내 링크로 궁합을 봤어요"(사람마다, 몰리면 묶음) · "○○ 님과의 궁합이 나왔어요". 점수 · 사이는 적지 않음. 밤 9시~아침 8시는 소리 없이.

### P3. 홈 메뉴판 · 탭 다섯 (결정 102)
- 홈: 오늘의 하늘 한 줄 → 나(내 별명 · 성격 · 연애 · 관계 · 일 · 감정 3×2) → 나의 시기(이번 달 · 올해 · 인생) → 나의 사람들(연애 궁합 · 친구 궁합 두 줄 → 궁합 입력, 사이 켜진 채).
- 아래 탭: 홈 · 나 · 시기 · 궁합 · 마이.

### P4. 작은 고침 (결정 103)
- 내 정보의 연결된 계정은 공급자 마크만(이메일 없음).
- 새 문의의 칸 이름 "유형".
- 공유 시트 아래 버튼을 나란히(이미지 저장 · 인스타그램 스토리) — 모든 공유가 같이 바뀜.

### P5. 음악 (결정 062 · 069 · 106 · 105)
- 앱 안 세 곡: 앱 열 때 · 로딩(풀이 쓰는 중 · 궁합 보는 중) · 배경. 음원은 팀원이 만든다(WAV 원본, 크레딧 없음).
- 마이 › 기본 설정 › 음악: 스위치 둘 — 배경 음악(앱 열 때 음악도 함께) · 로딩 음악. 처음엔 켬, 기기에만 저장, 줄 설명 없음.
- 휴대폰 규칙(무음 · 다른 앱 소리 · 뒤로 가면 멈춤)과 웹 규칙(누른 뒤부터, 앱 열 때 음악 없음)은 062 그대로.
- 스토리 공유에는 음악을 넣지 않는다(결정 105).

### P6. 공지사항 (결정 107)
- 마이 › 고객 지원 맨 위 "공지사항 ›" → 목록(새 글부터, 갈래 배지 공지 · 업데이트, 안 읽은 글 점) → 글(본문은 그냥 글자).
- 관리자가 "알림 보내기"를 켠 글만 공개할 때 한 번 알림함 + 푸시. 서비스 안내에만, 홍보는 어드민 "푸시 발송"(광고).
- 어드민: 소식 · 글 › 공지사항(웹 · 패드 · 폰 반응형).

## 1.1.0 에 넣지 않는 것
- 광고 · 광고 제거 상품(결정 100). GA4 도 계속 미룸.
- 궁합의 사이 넷(일 · 가족), 낮은 점수 표시, 궁합 유료(결정 104).
- 스토리 공유 음악(결정 105).
- 방향성 제시 · 친구창 · 투두 · 그룹 궁합(결정 100).
- 웹 결제, 웹으로 궁합 보기(안드로이드 · 컴퓨터의 링크 이어 보기는 예외 — 결정 104 의 7).
- 공지 예약 공개 · 맨 위 고정(결정 107).

## 출시 기준
- 결제: 샌드박스에서 사기 · 복원 · 다른 기기 · 1.0.0 수령자 열림 · 402 → 결제 시트가 iOS 에서 된다. 스토어 가격(4,990원 · 2,990원)이 목록에 있다.
- 궁합: 직접 입력 → 결과(요약 + 자세한 풀이 한 번에)까지 iOS 기기에서 된다. 지우기 · 편집 · 공유 카드 · 스토리 링크 복사가 된다.
- 링크 묶음(밀리면 1.1.x): 공유하기(카카오톡으로 보내 보기) → 받은 사람 다섯 갈래 → 보낸 사람 새로 온 별 → 알림이 실제 계정 둘로 된다.
- 음악: 세 곡이 실제 음원으로 바뀌고 스위치 둘이 기기에서 동작한다(무음 모드 · 다른 앱 소리 · 뒤로 감).
- 공지사항: 어드민에서 쓰기 · 공개 · 알림 보내기 → 앱 목록 · 글 · 알림함 · 푸시가 된다.
- 약관 · 개인정보 처리방침 개정이 시행 전에 공지된다(랜딩 · 이메일). **공지한 날 바로 시행한다**(소유자 "30일 공지 이거 없애" — 지금 글의 30일 약속과 어긋나는 위험은 사용자가 아주 적어 작다고 봄, 결정 108). 1.1.0 새 글의 변경 공지는 7일 전. 앱 공지사항은 1.1.0 부터라 이번엔 랜딩 · 이메일. 글은 앱 `src/content/legal.ts` 와 랜딩 사본을 같이 바꾼다. 초안: docs/drafts/2026-11-27-legal-1.1.0.md
- 궁합 글을 만들 때 상대 이름은 AI 에 보내지 않는다(지금 서버 `SynastryFacts` 그대로).
- 서버 main → 앱 main 순서(앱이 부르는 계약이 서버 main 에 먼저 있다).
