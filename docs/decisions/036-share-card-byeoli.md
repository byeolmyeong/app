# 036. 공유 카드에 별이와 로고를 넣는다("별이와 함께")

> 상태: 활성 · 결정일 2026-11-18 · 결정 025 의 1("카드에 더하는 것은 앱 이름과 한 줄 소개뿐")을 대체한다. 서버 `card` 계약과 025 의 나머지(앱 · 웹의 이미지 · 링크 공유, 공유 주소, 내 이름 묻기, 공유 페이지의 세션)는 그대로다. 시안: https://claude.ai/artifact/7HrHnKwEWBM2A3ovwxPqiL · 계획: docs/plans/2026-11-18-brand-assets.md 태스크 4b

## 맥락
- 지금 카드는 어두운 바탕에 앱 이름(글자)과 서버가 준 글만 있다. 브랜드 그림(결정 035)이 생겨 카드에도 넣을지 시안 세 가지(밤하늘 타이포 · 별이와 함께 · 유리 구슬)를 보였다.
- 소유자: "좋은데?? B 로 하자" (2026-11-18).
- 웹의 "이미지 저장" 은 `html2canvas-pro` 로 카드를 그리는데, SVG 의 흐림 필터를 그리지 못할 수 있다.

## 결정
1. 카드 위에 별이, 가운데에 서버가 준 글(가운데 맞춤), 아래에 로고(구슬 받침 레터링)와 한 줄 소개. 바탕은 위쪽이 옅게 빛나는 밤색과 옅은 별 점.
2. 별이의 표정은 카드 종류로만 정한다: 내 별명 · 랭킹 = 기본, 궁합 점수 = 반가움, 다음 변곡점 = 생각 중. **점수에 따라 표정을 바꾸지 않는다**(앱이 점수를 판단하지 않게, golden-rules "궁합 점수는 서버 값만").
3. 별이 · 로고 · 바탕은 `assets/brand/share-*.svg` 에서 만든 PNG(`assets/images/share/`)로 넣는다. 앱의 미리보기 · 저장 이미지 · 공유 페이지가 같은 그림이 된다. 로고 이미지는 화면 읽기에서 앱 이름으로 읽힌다.
4. 카드의 글 내용과 순서는 그대로다(`card` 의 값만, 출생 정보 · 근거 · 본문은 넣지 않는다).

## 근거
- 별이가 카드마다 나오면 공유된 카드만 보고도 어느 앱인지 알 수 있다.
- PNG 는 앱(`react-native-view-shot`)과 웹(`html2canvas-pro`)이 모두 그대로 그린다.

## 대안
- A 밤하늘 타이포(지금 카드를 다듬기) · C 유리 구슬(가운데 구슬에 숫자) — 소유자가 고르지 않았다.
- 별이를 SVG 부품으로 그리기 — 웹 이미지 저장에서 빛이 빠질 수 있다.

## 결과·재검토 조건
- 그림을 고치면 `assets/brand/share-*.svg` 를 고치고 `node scripts/render-brand.mjs` 를 다시 돌린다.
- 링크 미리보기(메신저에 붙였을 때의 그림)는 여전히 공유 페이지의 고정 문구다(025 의 재검토 조건 그대로).
